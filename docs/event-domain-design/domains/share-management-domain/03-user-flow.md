## 📍 Scenario 1: 페이지 소유자가 페이지 게시

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 1 in `02-process-model.md`
- **사용자 목표**: 작성한 페이지를 공개 링크로 게시
- **주요 제약**:
  - 페이지 소유자만 게시 가능
  - 게시 링크 형식은 `/p/[token]`
  - 게시 시점 스냅샷 기준으로 공개됨

---

### Screen 1: 페이지 편집 화면 (게시 트리거)

**화면 구성**:
- **상단 바**: 페이지 제목, 공유/게시 버튼
- **본문 영역**: 페이지 콘텐츠 편집 영역
- **보조 영역** (선택): 페이지 메타 정보

**UI 컴포넌트**:
- **게시 버튼**:
  - 라벨: "게시"
  - 상태: 소유자만 활성화
- **페이지 콘텐츠 영역**:
  - 블록 편집 UI

**권한별 UI 차이**:
- **소유자**:
  - 게시 버튼 활성화
- **비소유자**:
  - 게시 버튼 비활성화 또는 숨김
  - *비활성화 상태일 경우 툴팁: "페이지 소유자만 게시할 수 있습니다"*

**인터랙션**:
- 게시 버튼 클릭 → 게시 확인 다이얼로그 표시

**화면 전환**:
- **조건**: 게시 버튼 클릭
- **전환**: Screen 1 → Screen 2
- **전환 방식**: 다이얼로그 표시

---

### Screen 2: 게시 확인 다이얼로그

**화면 구성**:
- **헤더**: "페이지 게시"
- **본문**: 게시 안내 메시지
- **액션 영역**: 게시/취소 버튼

**UI 컴포넌트**:
- 안내 메시지
  - "'{페이지 제목}'를 게시하시겠습니까?"
  - "게시된 페이지는 누구나 링크로 접근할 수 있습니다"
  - "게시 시점의 버전이 고정됩니다"
- 버튼: "게시", "취소"

**인터랙션**:
- 게시 클릭 → 게시 진행 상태로 전환
- 취소 클릭 → 다이얼로그 닫기
- ESC/외부 클릭 → 다이얼로그 닫기

**화면 전환**:
- **조건**: 게시 클릭
- **전환**: Screen 2 → Screen 3
- **전환 방식**: 다이얼로그 내 상태 전환

---

### Screen 3: 게시 결과 피드백

**성공 시**:
- **UI 반응**: 게시 완료 메시지 + 링크 표시
- **메시지**: "게시가 완료되었습니다"
- **다음 액션**: 링크 복사 버튼 제공
- **보조 액션**: "게시된 페이지 보기" 또는 "공유하기" 버튼

**실패 시**:
- **UI 반응**: 에러 메시지 표시
- **메시지**: "게시에 실패했습니다. 다시 시도해주세요"
- **다음 액션**: 재시도 버튼

---

## 📍 Scenario 2: 비회원이 게시 링크 접속 및 복제 시도

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 2 in `02-process-model.md`
- **사용자 목표**: 게시된 페이지를 보고, 필요하면 복제 시도
- **주요 제약**:
  - 비회원은 읽기만 가능
  - 복제 시도 시 로그인 필요

---

### Screen 1: 게시된 페이지 뷰어 (비회원)

**화면 구성**:
- **상단 영역**: 페이지 제목, 페이지 아이콘
- **본문 영역**: 읽기 전용 콘텐츠
- **액션 영역**: 링크 복제 버튼, 페이지 복제 버튼

**UI 컴포넌트**:
- **읽기 전용 페이지 뷰어**
- **링크 복제 버튼**
- **페이지 복제 버튼**
- **읽기 전용 안내 배너/텍스트**: "이 페이지는 게시된 읽기 전용 페이지입니다"

**권한별 UI 차이**:
- **비회원**:
  - 복제 버튼 클릭 시 로그인 유도
  - 편집 불가 (커서/입력 불가)

**인터랙션**:
- 링크 복제 클릭 → 클립보드 복사 + 토스트
- 페이지 복제 클릭 → 로그인 안내 다이얼로그

**화면 전환**:
- **조건**: 페이지 복제 클릭
- **전환**: Screen 1 → Screen 2
- **전환 방식**: 다이얼로그 표시

---

### Screen 2: 로그인 안내 다이얼로그

**화면 구성**:
- **헤더**: "로그인 필요"
- **본문**: 로그인 안내 메시지
- **액션 영역**: 로그인 버튼

**UI 컴포넌트**:
- 메시지
  - "페이지를 복제하려면 로그인이 필요합니다"
  - "로그인 후 복제를 계속 진행할 수 있습니다"
- 버튼: "로그인"

**인터랙션**:
- 로그인 클릭 → 로그인 페이지로 이동

**화면 전환**:
- **조건**: 로그인 성공
- **전환**: Scenario 3의 Screen 2로 복귀
- **전환 방식**: 리다이렉트 (`?action=copy&token=...` 유지)
- **사용자 관점**: 로그인 완료 후 복제 다이얼로그가 자동으로 다시 열림

---

## 📍 Scenario 3: 회원이 게시 링크 접속 및 페이지 복제

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 3 in `02-process-model.md`
- **사용자 목표**: 게시된 페이지를 복제하여 내 워크스페이스에 생성
- **주요 제약**:
  - 회원만 복제 가능
  - 복제 대상 워크스페이스 선택 필요

---

### Screen 1: 게시된 페이지 뷰어 (회원)

**화면 구성**:
- **상단 영역**: 페이지 제목, 페이지 아이콘
- **본문 영역**: 읽기 전용 콘텐츠
- **액션 영역**: 링크 복제 버튼, 페이지 복제 버튼

**UI 컴포넌트**:
- **읽기 전용 페이지 뷰어**
- **링크 복제 버튼**
- **페이지 복제 버튼**

**권한별 UI 차이**:
- **회원**:
  - 복제 버튼 즉시 활성화
  - 편집 불가 (커서/입력 불가)

**인터랙션**:
- 링크 복제 클릭 → 클립보드 복사 + 토스트
- 페이지 복제 클릭 → 복제 확인 다이얼로그

**화면 전환**:
- **조건**: 페이지 복제 클릭
- **전환**: Screen 1 → Screen 2
- **전환 방식**: 다이얼로그 표시

---

### Screen 2: 복제 확인 + 워크스페이스 선택

**화면 구성**:
- **헤더**: "페이지 복제"
- **본문**: 복제 안내 + 워크스페이스 목록
- **액션 영역**: 복제/취소 버튼

**UI 컴포넌트**:
- 복제 안내 메시지
  - "'{페이지 제목}'를 복제하시겠습니까?"
  - "복제된 페이지는 선택한 워크스페이스에 생성됩니다"
- 워크스페이스 선택 리스트
  - 이름, 아이콘, 조직명 표시
- 버튼: "복제", "취소"

**인터랙션**:
- 워크스페이스 선택 → 선택 상태 표시
- 복제 클릭 → 복제 진행 상태로 전환
- 취소 클릭 → 다이얼로그 닫기
- 워크스페이스 미선택 시 복제 버튼 비활성화

**화면 전환**:
- **조건**: 복제 클릭
- **전환**: Screen 2 → Screen 3
- **전환 방식**: 다이얼로그 내 상태 전환

---

### Screen 3: 복제 결과 피드백

**성공 시**:
- **UI 반응**: "복제가 완료되었습니다" 메시지
- **다음 액션**: 복제된 페이지로 이동 버튼

**실패 시**:
- **UI 반응**: 에러 메시지 표시
- **다음 액션**: 재시도 버튼
- **복구 흐름**: 실패 시 워크스페이스 선택 상태로 복귀

---

## 📱 반응형 고려사항

### 데스크톱 (1024px 이상)
- 게시된 페이지 뷰어는 중앙 정렬, 넓은 본문 폭
- 복제 다이얼로그는 중앙 모달

### 태블릿 (768px - 1023px)
- 본문 폭 축소
- 다이얼로그는 화면 폭에 맞춤

### 모바일 (767px 이하)
- 뷰어 상단 액션 버튼을 하단 고정 영역으로 이동
- 로그인 안내, 복제 확인 다이얼로그는 Bottom Sheet로 대체
