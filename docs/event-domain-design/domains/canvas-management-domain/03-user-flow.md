### 문서 목적

이 문서는 Canvas Management Domain의 사용자 여정을 정의합니다.  
Process Model의 비즈니스 프로세스를 기반으로 실제 화면 흐름과 사용자 인터랙션을 상세히 설명합니다.

**범위**:
- 캔버스 사용자 화면 흐름 정의
- 블럭/엣지 조작 UI 컴포넌트 및 인터랙션 명세
- 권한별 UI 차이 정의
- 에러 처리 및 피드백 방법

**제외 사항** (Frontend Specification에서 다룸):
- React Flow 컴포넌트 구현 상세
- 상태 관리 방법 (React Flow State ↔ DB)
- Server Actions 연동

## 📍 Scenario 0: 외부 도메인과의 동기화

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 0 in `02-process-model.md`
- **사용자 목표**: 페이지 접근 시 캔버스가 올바르게 초기화되고 기존 데이터가 복원되어야 함
- **주요 제약**: 페이지 접근 권한 확인 필수, 빈 페이지와 기존 페이지 구분 필요

---

### Screen 1: 빈 캔버스 초기 화면

**화면 구성**:
- **헤더 영역**: 페이지 제목, 즐겨찾기 버튼, 공유 버튼
- **본문 영역**: 빈 캔버스 영역, 도구바 (상단)
- **상태 표시**: 로딩 인디케이터 (초기화 중)

**UI 컴포넌트**:
- **캔버스 영역** (React Flow): 
  - 무한 확대/축소 지원
  - 빈 배경에 그리드 표시
  - 마우스 휠 줌, 트랙패드/마우스 드래그 패닝
- **도구바** (상단): 
  - 플러스(+) 버튼 하나로 통합 (블럭 추가)
  - 클릭 시 블럭 타입 선택 다이얼로그 표시
  - 도형, 유튜브, 이미지, 영상, 지도 등 수많은 타입 지원
- **뷰포트 컨트롤** (우측 하단): 
  - 줌 인/아웃 버튼
  - 미니맵 토글 버튼
  - 현재 줌 레벨 표시

**권한별 UI 차이**:
- **관리자/소유자**:
  - 모든 블럭 타입과 도구 접근 가능
  - 캔버스 편집 모드 활성화
  
- **편집 권한 사용자**:
  - 제한된 블럭 타입만 접근 가능
  - 캔버스 편집 모드 활성화
  
- **읽기 전용 사용자**:
  - 블럭 타입 선택 비활성화
  - 도구바 숨김 또는 비활성화

**인터랙션**:
- 플러스 버튼 클릭 → 블럭 타입 선택 다이얼로그 표시
- 블럭 타입 선택 → 다이얼로그 닫기, 블럭 생성 모드 활성화
- 빈 캔버스 영역 클릭 → 선택된 블럭 타입으로 새 블럭 생성
- 마우스 휠 → 캔버스 줌 인/아웃
- 트랙패드/마우스 드래그 → 뷰포트 패닝
- ESC 키 → 블럭 생성 모드 취소

**화면 전환**:
- **조건**: 블럭 생성 완료
- **전환**: Screen 1 → Screen 1 (같은 화면, 새 블럭 추가)
- **전환 방식**: 인라인 업데이트 (새 블럭이 애니메이션과 함께 나타남)

---

### Screen 2: 기존 캔버스 로드 화면

**화면 구성**:
- **헤더 영역**: 페이지 제목, 즐겨찾기 버튼, 공유 버튼
- **본문 영역**: 로딩된 블럭들과 엣지들이 표시된 캔버스, 도구바
- **로딩 상태**: 전체 캔버스 로딩 인디케이터

**UI 컴포넌트**:
- **캔버스 영역** (React Flow):
  - 기존 블럭들 위치와 크기로 표시
  - 기존 엣지들 연결 상태로 표시
  - 복원된 뷰포트 상태 (줌, 중심 좌표)
- **도구바** (상단): 
  - 플러스(+) 버튼 (블럭 추가)
  - 클릭 시 블럭 타입 선택 다이얼로그
- **뷰포트 컨트롤** (우측 하단): 
  - 줌 인/아웃 버튼, 미니맵 토글, 줌 레벨 표시

**인터랙션**:
- 로딩 완료 전까지 캔버스 조작 불가
- 로딩 완료 후 일반 캔버스 인터랙션 활성화
- 마우스 휠 → 캔버스 줌 인/아웃
- 캔버스 드래그 → 뷰포트 패닝

**화면 전환**:
- **조건**: 모든 블럭과 엣지 로딩 완료
- **전환**: 로딩 상태 → 정상 편집 모드
- **전환 방식**: 페이드 인 애니메이션

---

### 에러 처리

**권한 부족**:
- **UI 반응**: 캔버스 영역에 "접근 권한이 없습니다" 오버레이 표시
- **메시지**: "이 페이지에 접근할 권한이 없습니다"

**로딩 실패**:
- **UI 반응**: 빈 캔버스 상태, 재시도 버튼 표시
- **메시지**: "캔버스를 불러올 수 없습니다"

## 📍 Scenario 1: 블럭 생성 및 마운팅

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 1 in `02-process-model.md`
- **사용자 목표**: 플러스 버튼으로 블럭 타입을 선택하고 캔버스에 원하는 위치에 배치하고 싶어함
- **주요 제약**: 블럭 타입별 기본 크기와 속성 적용, Z-Order 최상위 배치

---

### Screen 1: 블럭 타입 선택 다이얼로그

**화면 구성**:
- **도구바**: 플러스(+) 버튼
- **블럭 타입 선택 다이얼로그**: 모달 형태로 표시
- **캔버스**: 빈 상태 또는 기존 블럭들 표시

**UI 컴포넌트**:
- **플러스 버튼** (상단 도구바):
  - 클릭 시 블럭 타입 선택 다이얼로그 표시
- **블럭 타입 선택 다이얼로그**:
  - 카테고리별 블럭 타입 목록 (도형, 유튜브, 이미지, 영상, 지도 등)
  - 각 타입에 아이콘과 이름 표시
  - 검색 기능
  - 취소/선택 버튼
- **캔버스 커서** (선택 후):
  - 블럭 타입 선택 시 커서 아이콘 변경
  - 마우스에 블럭 스켈레톤 표시 (반투명 프리뷰)

**인터랙션**:
- 플러스 버튼 클릭 → 블럭 타입 선택 다이얼로그 표시
- 다이얼로그에서 타입 선택 → 다이얼로그 닫기, 블럭 생성 모드 활성화
- 캔버스 호버 (모드 활성화 시) → 마우스에 블럭 스켈레톤 표시
- 빈 영역 클릭 → 해당 위치에 블럭 생성 및 배치
- ESC 키 → 블럭 생성 모드 취소, 다이얼로그 닫기

**화면 전환**:
- **조건**: 블럭 생성 완료
- **전환**: Screen 1 → Screen 2 (블럭 편집 모드)
- **전환 방식**: 새 블럭이 나타나면서 자동 선택 상태

---

### Screen 2: 새 블럭 생성 완료 (단일 블럭 편집 모드)

**화면 구성**:
- **캔버스**: 새로 생성된 블럭이 선택된 상태로 표시
- **블럭 탑 툴바**: 선택된 블럭 위에 표시되는 툴바 (node-top-toolbar 참고)
- **단일 블럭 편집 모드**: 블럭 내부 컨텐츠 편집 활성화

**UI 컴포넌트**:
- **선택된 블럭**:
  - 테두리 강조 표시 (파란색 또는 포인트 색상)
  - 리사이즈 핸들 (8방향 핸들)
  - 선택 표시기
- **블럭 탑 툴바** (블럭 위에 표시, node-top-toolbar.tsx 참고):
  - ">>" 버튼 (Details): 에디터 패널 열기/닫기
  - "..." 드롭다운 메뉴:
    - Edit (⌘E), Duplicate (⌘D), Create Component, Delete (⌫)
    - 블럭 타입별 추가 옵션들
- **단일 블럭 편집 모드**:
  - 블럭 내 텍스트 area 등이 활성화됨
  - 캔버스 전체 조작과 블럭 조작 명확히 구분
  - 다른 블럭 클릭하거나 빈 영역 클릭 시 편집 모드 해제

**인터랙션**:
- 블럭 클릭 → 단일 블럭 편집 모드 활성화 (내부 컨텐츠 편집 가능)
- 다른 블럭 클릭 → 이전 블럭 편집 모드 해제, 새 블럭 편집 모드
- 빈 영역 클릭 → 모든 블럭 편집 모드 해제
- 블럭 드래그 → 위치 변경 (실시간)
- 리사이즈 핸들 드래그 → 크기 변경 (실시간)
- DEL 키 → 블럭 삭제 확인 다이얼로그
- Ctrl+D → 블럭 복제

**화면 전환**:
- **조건**: 다른 블럭 클릭 또는 빈 영역 클릭
- **전환**: Screen 2 → Screen 1 (다시 블럭 타입 선택 대기)
- **전환 방식**: 선택 해제

---

### 에러 처리

**블럭 생성 실패**:
- **UI 반응**: Toast 메시지 표시, 캔버스 커서 초기화
- **메시지**: "블럭을 생성할 수 없습니다. 다시 시도해주세요"

**권한 부족**:
- **UI 반응**: 블럭 타입 버튼 비활성화, 툴팁으로 권한 안내
- **메시지**: "이 블럭 타입을 생성할 권한이 없습니다"

## 📍 Scenario 2: 블럭 변환 (이동, 리사이즈, Z-Order)

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 2 in `02-process-model.md`
- **사용자 목표**: 블럭을 드래그해서 원하는 위치로 이동시키고, 크기를 조정하고 싶어함
- **주요 제약**: 실시간 업데이트 (React Flow State), 드래그 종료 시에만 DB 저장, 스냅 가이드라인 지원

---

### Screen 1: 블럭 드래그 이동 중

**화면 구성**:
- **캔버스**: 드래그 중인 블럭과 실시간 위치 업데이트
- **가이드라인**: 다른 블럭과의 정렬 가이드라인 표시

**UI 컴포넌트**:
- **드래그 중인 블럭**:
  - React Flow의 기본 동작에 따라 실시간 위치 업데이트
  - 시각적 효과 없음 (React Flow 기본 상태 유지)
- **스냅 가이드라인**:
  - 다른 블럭과의 정렬 가능한 위치에 점선 표시
  - 중심선 (세로/가로), 가장자리 정렬선
  - 가이드라인 위에 있을 때 하이라이트 효과

**인터랙션**:
- 블럭 드래그 → React Flow 기본 동작으로 실시간 위치 업데이트, 가이드라인 계산 및 표시
- 5px 임계값 내 진입 → 자동 스냅 가이드라인 하이라이트
- 드래그 종료 → 최종 위치 확정, DB 저장
- ESC 키 → 드래그 취소, 원래 위치로 복원

**애니메이션**:
- 가이드라인 표시/숨김: 200ms 페이드 인/아웃
- 스냅 하이라이트: 150ms ease-out

---

### Screen 2: 블럭 리사이즈 중

**화면 구성**:
- **캔버스**: 리사이즈 중인 블럭과 실시간 크기 업데이트
- **크기 표시**: 현재 크기 (width x height) 표시
- **제한 표시**: 최소/최대 크기 제한 경계

**UI 컴포넌트**:
- **리사이즈 중인 블럭**:
  - 리사이즈 핸들 하이라이트
  - 실시간 크기 변경 반영
  - 최소/최대 크기 제한 시 시각적 피드백
- **크기 정보 표시**:
  - 블럭 위 또는 별도 패널에 현재 크기 표시
  - 최소/최대 크기 도달 시 경고 표시
- **리사이즈 핸들**:
  - 8방향 핸들 (상하좌우 + 대각선)
  - 호버 시 커서 변경
  - 활성 핸들 강조 표시

**인터랙션**:
- 리사이즈 핸들 드래그 → 실시간 크기 변경
- 최소/최대 크기 도달 → 드래그 제한, 시각적 피드백
- 리사이즈 종료 → 최종 크기 확정, DB 저장
- SHIFT 드래그 → 비율 유지 리사이즈

**애니메이션**:
- 크기 변경: 즉시 반영 (실시간)
- 제한 도달: 300ms 진동 효과

---

### Screen 3: 드래그/리사이즈 종료 및 확정

**화면 구성**:
- **캔버스**: 최종 위치/크기로 블럭 고정
- **선택 상태**: 변경된 블럭이 선택된 상태 유지

**UI 컴포넌트**:
- **확정된 블럭**:
  - 선택 테두리 유지
  - 최종 위치/크기로 고정

**인터랙션**:
- 다른 블럭 클릭 → 새 블럭 선택
- 빈 영역 클릭 → 선택 해제
- 바로 다른 편집 시작 가능

**화면 전환**:
- **조건**: 다른 작업 시작
- **전환**: Screen 3 → 해당 작업 화면
- **전환 방식**: 자연스러운 상태 전환

---

### 에러 처리

**위치 변경 실패**:
- **UI 반응**: 원래 위치로 되돌리기, 에러 Toast
- **메시지**: "위치 변경에 실패했습니다"

**크기 제한 초과**:
- **UI 반응**: 최대/최소 크기로 제한, 시각적 피드백
- **메시지**: "최대/최소 크기 제한에 도달했습니다"

## 📍 Scenario 3: 블럭 복제

---

### Screen 3: 삭제 완료 및 정리

**화면 구성**:
- **정리된 캔버스**: 삭제된 블럭과 연결된 엣지들이 제거된 상태
- **완료 피드백**: 삭제 완료 시각적 피드백
- **상태 정규화**: 다음 작업을 위한 준비된 캔버스 상태

**UI 컴포넌트**:
- **정리된 캔버스**:
  - 삭제된 블럭 공간이 빈 공간으로 표시
  - 연결된 엣지들도 함께 제거됨
  - 다른 블럭들은 영향받지 않음
- **삭제 완료 피드백**:
  - 삭제된 영역에 일시적 페이드 아웃 효과

**인터랙션**:
- 다른 블럭 선택 가능
- 새로운 블럭 생성 가능
- 일반적인 캔버스 작업 재개

**애니메이션**:
- 블럭 삭제: 400ms 페이드 아웃 + 스케일 다운
- 엣지 삭제: 300ms 페이드 아웃
- 완료 피드백: 200ms Toast 표시

---

### 에러 처리

**삭제 실패**:
- **UI 반응**: 원래 상태 복원, 에러 Toast
- **메시지**: "블럭 삭제에 실패했습니다"

**권한 부족**:
- **UI 반응**: 삭제 버튼 비활성화, 권한 안내 툴팁
- **메시지**: "이 블럭을 삭제할 권한이 없습니다"

## 📍 Scenario 9: 캔버스 뷰포트 관리

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 9 in `02-process-model.md`
- **사용자 목표**: 캔버스를 확대/축소하고 이동해서 원하는 영역을 보고 싶어함
- **주요 제약**: 줌 레벨 제한, 페이지 이탈 시 상태 저장, 자동 복원

---

### Screen 1: 캔버스 줌 및 패닝

**화면 구성**:
- **캔버스**: 줌/패닝 가능한 React Flow 캔버스
- **줌 컨트롤**: 줌 인/아웃 버튼, 줌 레벨 표시
- **뷰포트 정보**: 현재 줌 레벨, 중심 좌표 표시

**UI 컴포넌트**:
- **뷰포트 컨트롤** (우측 하단):
  - 줌 인 버튼 (+)
  - 줌 아웃 버튼 (-)
  - 현재 줌 레벨 표시 (예: 100%, 150%)
  - "원래 크기" 버튼 (100%로 리셋)
- **패닝 컨트롤**:
  - 트랙패드: 1:1 대응되는 자연스러운 이동
  - 마우스 드래그: 트랙패드와 유사한 움직임
- **미니맵** (토글 가능):
  - 전체 캔버스의 축소된 뷰
  - 현재 뷰포트 영역 표시

**인터랙션**:
- 마우스 휠 → 줌 인/아웃 (마우스 커서 중심)
- Ctrl + 마우스 휠 → 더 빠른 줌
- 트랙패드/마우스 드래그 → 패닝 (이동)
- 뷰포트 컨트롤 버튼 → 정확한 줌 조절
- 미니맵 클릭 → 해당 영역으로 즉시 이동

**화면 전환**:
- **조건**: 줌/패닝 조작
- **전환**: 즉시 반영 (애니메이션 없음)
- **전환 방식**: 부드러운 줌/패닝 전환

---

### Screen 2: 블럭 포커스 및 화면 맞춤

**화면 구성**:
- **포커스 대상**: 포커스할 블럭
- **자동 뷰포트 조정**: 블럭이 화면 중앙에 오도록 조정
- **애니메이션**: 부드러운 이동 애니메이션

**UI 컴포넌트**:
- **포커스 트리거**:
  - 블럭 더블클릭
  - 블럭 우클릭 메뉴의 "포커스" 옵션
  - 블럭 목록에서 블럭 선택
- **자동 조정**:
  - 적절한 줌 레벨로 조정
  - 블럭이 화면 중앙에 위치
  - 주변 블럭들도 적절히 보이도록 조정

**인터랙션**:
- 블럭 더블클릭 → 해당 블럭으로 포커스 이동
- 포커스 액션 → 부드러운 애니메이션으로 이동
- 포커스 완료 → 블럭 선택 상태로 전환

**애니메이션**:
- 뷰포트 이동: 800ms ease-out 애니메이션
- 줌 조정: 600ms ease-in-out 애니메이션

---

### Screen 3: 뷰포트 상태 저장 및 복원

**화면 구성**:
- **자동 저장**: 페이지 이탈 시 자동으로 뷰포트 상태 저장
- **자동 복원**: 페이지 재진입 시 이전 뷰포트 상태 복원

**UI 컴포넌트**:
- **자동 저장/복원**:
  - 페이지 이탈 시 백그라운드에서 자동 저장
  - 페이지 재진입 시 자동으로 이전 상태 복원
  - 사용자에게 별도 알림 없음

**인터랙션**:
- 페이지 이탈 → 자동 뷰포트 상태 저장
- 페이지 재진입 → 자동 이전 상태 복원
- 복원 완료 → 사용자 작업 가능

**화면 전환**:
- **조건**: 페이지 진입
- **전환**: 로딩 → 복원된 뷰포트 상태
- **전환 방식**: 자연스러운 상태 복원

---

### 에러 처리

**뷰포트 복원 실패**:
- **UI 반응**: 기본 뷰포트 상태로 시작, 에러 표시 없음
- **메시지**: 기본 상태로 시작 (사용자에게 알리지 않음)

**줌 제한 도달**:
- **UI 반응**: 더 이상 줌 인/아웃 불가, 시각적 피드백
- **메시지**: 부드러운 제한 (시각적 신호로만 표시)

## 📱 반응형 고려사항

### 데스크톱 (> 1024px)
- **레이아웃**: 
  - 도구바를 상단에 고정 (플러스 버튼)
  - 사이드바 편집 패널 지원
  - 뷰포트 컨트롤 우하단 고정
- **인터랙션**: 
  - 마우스 휠 줌, 트랙패드/마우스 드래그 패닝
  - 키보드 단축키 지원 (⌘E, ⌘D, ⌫ 등)
  - 블럭 탑 툴바 및 엣지 탑 툴바 활용
- **특이사항**: 
  - 복잡한 다이얼로그와 편집 패널 활용

### 태블릿 (768px ~ 1024px)
- **레이아웃**: 
  - 도구바를 상단으로 이동하거나 접을 수 있는 형태
  - 편집 패널을 바텀 시트로 변경
- **인터랙션**: 
  - 터치 줌/패닝 확대
  - 터치 영역 최소 44px 보장
- **특이사항**: 
  - 손가락으로 정확한 조작을 위한 여유 공간 확보

### 모바일 (< 768px)
- **레이아웃**: 
  - 도구바를 하단 또는 플로팅 액션 버튼으로 변경
  - 편집 패널을 전체 화면 모달로 변경
  - 미니맵을 오버레이 형태로 표시
- **인터랙션**: 
  - 핀치 줌 (두 손가락)
  - 터치 드래그 패닝
  - 롱프레스 컨텍스트 메뉴
- **특이사항**: 
  - 작은 화면에서의 정확한 블럭 선택을 위한 확대 기능
  - 스와이프 제스처 고려
