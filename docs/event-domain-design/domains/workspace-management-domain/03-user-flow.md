## 📍 Scenario 1: 조직 접근 및 Workspace-Page 목록 조회 및 페이지 선택

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 1 in `02-process-model.md`
- **사용자 목표**: 
  - 조직 페이지에 접근하여 모든 Workspace의 Page 목록을 확인
  - 작업할 페이지를 선택하여 열기
  - 최근 방문한 페이지로 자동 이동
  
- **주요 제약**: 
  - 조직 멤버만 접근 가능
  - Workspace 멤버십에 따라 페이지 접근 제한
  - Default Workspace는 조직 멤버 모두 접근 가능
  - 일반 Workspace는 초대받은 멤버만 접근 가능

### Screen 1: 조직 Workspace 레이아웃 (로딩 상태)

**화면 구성**:
```
┌─────────────────────────────────────────────────────────────┐
│ [조직 선택 ▼]                                               │
├──────────────────┬──────────────────────────────────────────┤
│                  │                                          │
│  [스켈레톤 라인] │    [페이지 제목 스켈레톤]                │
│  [스켈레톤 라인] │                                          │
│  [스켈레톤 라인] │    [캔버스 콘텐츠 스켈레톤 블록들]        │
│  [스켈레톤 라인] │                                          │
│  [스켈레톤 라인] │                                          │
│                  │                                          │
└──────────────────┴──────────────────────────────────────────┘
  ↑ 사이드바 (280px)   ↑ 메인 영역
```

**UI 컴포넌트**:

**헤더 영역**:
- **조직 선택 드롭다운** (`OrganizationSwitcher`):
  - 현재 선택된 조직명 표시
  - 드롭다운 아이콘 (ChevronDown)
  - Organization Domain 컴포넌트 재사용

**사이드바 영역 (로딩 중)**:
- **너비**: 280px (데스크톱)
- **스켈레톤 UI**:
  - 스켈레톤 라인 5-7개
  - shimmer 애니메이션 효과
  - 높이: 각 라인 24px
  - 간격: 8px
  - 배경: gray-200
  
**메인 영역 (로딩 중)**:
- **페이지 헤더 스켈레톤**:
  - 제목 라인 (너비: 200px, 높이: 32px)
  - 부제 라인 (너비: 120px, 높이: 16px)
  
- **캔버스 스켈레톤**:
  - 블록 스켈레톤 3-5개
  - 각 블록: 높이 40-80px (랜덤)
  - 여백: 좌우 96px (데스크톱)

**인터랙션**:
- 인터랙션 없음 (로딩 중)

**화면 전환**:
- **조건**: 데이터 로드 완료
- **전환**: Screen 1 → Screen 2
- **전환 방식**: 스켈레톤에서 실제 콘텐츠로 fade-in

**애니메이션**:
- 스켈레톤 shimmer 효과: 좌→우 방향, 1.5s 반복
- 전환 애니메이션: fade-in 150ms ease-in-out

### Screen 2: 조직 Workspace 레이아웃 (로드 완료)

**화면 구성**:
```
┌─────────────────────────────────────────────────────────────┐
│ [조직 선택 ▼]                                               │
├──────────────────┬──────────────────────────────────────────┤
│ ⭐ 즐겨찾기       │ 📄 페이지 제목                           │
│   📄 중요 기획   │                                          │
│   📄 회의록      │                                          │
│                  │ [캔버스 콘텐츠]                          │
│ 📁 Acme Corp     │                                          │
│   📄 Welcome     │                                          │
│   📄 팀 소개     │                                          │
│                  │                                          │
│ 📁 마케팅 팀     │                                          │
│   📄 캠페인 계획 │                                          │
│   › 📄 Q1 계획   │                                          │
│     📄 1월       │                                          │
│     📄 2월       │                                          │
│                  │                                          │
│ 📁 개발 팀       │                                          │
│   📄 로드맵      │                                          │
│                  │                                          │
└──────────────────┴──────────────────────────────────────────┘
```

**UI 컴포넌트**:

**사이드바 영역** (메인 콘텐츠):

1. **즐겨찾기 섹션** (최상단):
   - **헤더**:
     - 아이콘: ⭐ (별)
     - 텍스트: "즐겨찾기" (font-semibold, text-sm)
     - 색상: text-gray-700
   
   - **즐겨찾기 페이지 목록** (플랫 리스트):
     - 각 페이지 아이템:
       - 페이지 아이콘 (16x16px)
       - 페이지 제목 (truncate)
       - 패딩: 8px 12px
       - 간격: 2px
     - 즐겨찾기 없는 경우:
       - 회색 텍스트: "즐겨찾기한 페이지가 없습니다"
       - 폰트 크기: text-xs
   
   - **구분선** (Separator):
     - 높이: 1px
     - 색상: border-gray-200
     - 여백: 상하 8px

2. **Workspace 섹션들**:
   
   **A. Default Workspace** (최상단, "기본 조직" 표시):
   - **헤더**:
     - 아이콘: 조직 아이콘 또는 기본 📁
     - 이름: 조직명 (예: "Acme Corp")
     - Chevron 아이콘: › (접기/펼치기)
     - "기본" 배지: 작은 회색 배지 (선택사항)
   
   - **페이지 트리**:
     - 접힌 상태: Chevron › (오른쪽 향함)
     - 펼쳐진 상태: Chevron ∨ (아래 향함)
     - 하위 페이지 목록 표시 (접기/펼치기 가능)
   
   **B. 일반 Workspace들**:
   - **헤더**:
     - 아이콘: Workspace별 커스텀 아이콘 (이모지 또는 이미지)
     - 이름: Workspace 이름 (예: "마케팅 팀")
     - Chevron 아이콘: › / ∨
   
   - **페이지 트리**: Default Workspace와 동일 구조

3. **페이지 아이템** (각 Workspace 내부):
   - **구조**:
     - 페이지 아이콘 (16x16px): 커스텀 아이콘 (기본: 📄)
     - 페이지 제목: truncate 처리
     - Chevron (하위 페이지 있는 경우): › / ∨
   
   - **들여쓰기** (계층 구조):
     - 최상위 페이지: 들여쓰기 없음
     - 1단계 하위: 16px 들여쓰기
     - 2단계 하위: 32px 들여쓰기
     - 3단계 이상: 48px 들여쓰기 (최대)
   
   - **상태 표시**:
     - 기본 상태: 배경 투명
     - 호버 상태: 배경 gray-50
     - 선택 상태: 배경 primary-50, 왼쪽 보더 (primary-500, 2px)
   
   - **하위 페이지 펼치기/접기**:
     - 부모 페이지 앞에 Chevron 표시
     - 클릭 시 하위 페이지 토글
     - 상태는 로컬 스토리지에 저장 (persistence)

4. **빈 Workspace 표시**:
   - 페이지가 0개인 경우:
     - 회색 텍스트: "페이지를 생성하세요"
     - 폰트 크기: text-xs
     - 색상: text-gray-500
     - 패딩: 8px 12px

**메인 영역**:

**페이지 헤더**:
- **페이지 아이콘**:
  - 크기: 32x32px
  - 클릭 가능 (편집용, Scenario 4에서 다룸)
  - 호버 시 배경 gray-100 (편집 힌트)

- **페이지 제목**:
  - 폰트: text-2xl, font-bold
  - 클릭 가능 (편집용, Scenario 4에서 다룸)
  - 호버 시 배경 gray-50 (편집 힌트)

- **메타 정보**:
  - 마지막 수정 시간 (text-xs, text-gray-500)
  - 예: "2분 전 수정됨"

**페이지 캔버스**:
- **여백**: 
  - 좌우: 96px (데스크톱)
  - 상단: 24px
  - 하단: 48px
  
- **콘텐츠**:
  - 블록 시스템 영역 (Block System Domain, 미래)
  - 현재는 빈 상태 또는 "Welcome" 기본 텍스트

**인터랙션**:

1. **페이지 아이템 클릭**:
   - **동작**:
     - 선택 상태 변경 (배경색 primary-50)
     - 이전 선택 해제
     - URL 변경: `/r/[orgId]/workspace/[workspaceId]/page/[pageId]`
     - 메인 영역에 페이지 콘텐츠 로드 (Screen 3으로 전환)
     - 쿠키에 pageId 저장 (key: `recent-page-${orgId}`, value: `<pageId>`)
     - Workspace 멤버십 검증 요청 (Server Component)
   
   - **로딩**:
     - 선택 상태는 즉시 변경 (낙관적 업데이트)
     - 메인 영역만 로딩 상태로 전환
     - 사이드바는 그대로 유지

2. **Workspace 헤더 Chevron 클릭**:
   - **동작**:
     - Chevron 방향 전환: › ↔ ∨
     - 하위 페이지 목록 토글 (펼치기/접기)
     - 로컬 스토리지에 상태 저장 (key: `workspace-collapsed-${workspaceId}`)
   
   - **애니메이션**:
     - 슬라이드 다운/업 (200ms ease-out)
     - 높이 자동 계산

3. **부모 페이지 Chevron 클릭**:
   - **동작**:
     - Chevron 방향 전환: › ↔ ∨
     - 하위 페이지 토글 (펼치기/접기)
     - 로컬 스토리지에 상태 저장 (key: `page-collapsed-${pageId}`)
   
   - **애니메이션**: Workspace와 동일

4. **페이지 아이템 호버**:
   - 배경색 변경: transparent → gray-50
   - 커서: pointer
   - 전환 시간: 100ms ease-in-out

5. **즐겨찾기 페이지 클릭**:
   - 페이지 아이템 클릭과 동일한 동작
   - 해당 Workspace의 페이지로 이동
   - Workspace 섹션도 자동으로 펼쳐짐

**권한별 UI 차이** (Software Design 기준):
- **조직 멤버 (공통)**:
  - 모든 Workspace 목록 표시 (초대 여부 무관)
  - Default Workspace의 모든 페이지 접근 가능 (자동 허용)
  - 일반 Workspace는 멤버십 확인 필요
  
- **Workspace 멤버**:
  - 초대받은 Workspace의 페이지 접근 가능
  - 초대받지 않은 Workspace의 페이지 클릭 시 → Screen 4 (권한 없음 페이지)
  
- **Workspace 비멤버**:
  - Workspace 목록에는 표시됨 (조직 멤버이므로 가시성 있음)
  - 페이지 클릭 시 Workspace 멤버십 검증 실패
  - 검증 실패 시 → Screen 4 (권한 없음 페이지)
  
- **조직 비멤버**:
  - 페이지 진입 자체가 차단됨 (Server Component에서 403 Forbidden)
  - Workspace-Page 목록 로드 전에 즉시 차단 (Fail-fast)

**화면 전환**:
- **조건 1**: 권한 있는 페이지 선택
  - **전환**: Screen 2 유지 (메인 영역만 업데이트)
  - **전환 방식**: 메인 영역 fade-out → Screen 3 (로딩) → fade-in

- **조건 2**: 권한 없는 페이지 선택
  - **전환**: Screen 2 → Screen 4 (권한 없음 페이지)
  - **전환 방식**: 메인 영역만 fade-out → fade-in

**애니메이션**:
- **페이지 전환**: 
  - 메인 영역 fade-out/in (150ms ease-in-out)
  - 사이드바는 애니메이션 없음
  
- **Workspace/페이지 펼치기/접기**: 
  - 슬라이드 다운/업 (200ms ease-out)
  - 높이 자동 계산 (max-height transition)
  
- **선택 상태 변경**: 
  - 즉시 적용 (애니메이션 없음)
  - 배경색만 transition (100ms)

**접근성**:
- **키보드 내비게이션**:
  - Tab: 페이지 아이템 간 이동
  - Enter/Space: 페이지 선택
  - Arrow Up/Down: 페이지 목록 탐색
  - Arrow Left/Right: Workspace/페이지 접기/펼치기
  
- **스크린 리더**:
  - 각 페이지 아이템에 aria-label
  - 선택 상태: aria-selected="true"
  - 펼침/접힘 상태: aria-expanded="true/false"

### Screen 3: 페이지 선택 중 (로딩 상태)

**화면 구성**:
- **사이드바**: Screen 2와 동일 (선택 상태만 변경됨)
- **메인 영역**: 스켈레톤 UI로 전환

**UI 컴포넌트**:

**사이드바**:
- Screen 2와 동일
- 선택된 페이지 아이템: 배경 primary-50, 왼쪽 보더 primary-500

**메인 영역 (로딩 중)**:
- **페이지 헤더 스켈레톤**:
  - 아이콘 스켈레톤 (32x32px 원형)
  - 제목 라인 (너비: 200px, 높이: 32px)
  - 부제 라인 (너비: 120px, 높이: 16px)

- **캔버스 스켈레톤**:
  - 블록 스켈레톤 3-5개
  - shimmer 애니메이션

**인터랙션**:
- **사이드바**: 여전히 클릭 가능 (다른 페이지 선택 가능)
  - 연속 클릭 가능 (여러 페이지를 빠르게 전환 가능)
  - 최신 클릭이 이전 요청을 취소함 (Race condition 방지)

- **메인 영역**: 인터랙션 비활성화
  - 포인터 이벤트 차단 (pointer-events: none)

**화면 전환**:
- **조건 1**: 페이지 로드 완료 + 권한 있음
  - **전환**: Screen 3 → Screen 2 (콘텐츠 업데이트)
  - **전환 방식**: fade-in (150ms)

- **조건 2**: 권한 검증 실패
  - **전환**: Screen 3 → Screen 4 (권한 없음 페이지)
  - **전환 방식**: fade-in (150ms)

**애니메이션**:
- 메인 영역 스켈레톤 shimmer 효과: 좌→우, 1.5s 반복
- 전환: fade-in 150ms ease-in-out

│                  │                                          │
└──────────────────┴──────────────────────────────────────────┘

- **설명**:
  - 텍스트: "Workspace에 초대되지 않았습니다"
  - 폰트: text-sm
  - 색상: text-gray-600
  - 여백 하단: 12px

- **안내 메시지**:
  - 텍스트: "조직 관리자에게 문의하세요"
  - 폰트: text-sm
  - 색상: text-gray-500

**인터랙션**:
- **사이드바**: 다른 페이지 선택 가능
  - 권한 있는 페이지 클릭 → Screen 2로 복귀
  - 다른 권한 없는 페이지 클릭 → Screen 4 유지 (메시지는 동일)

- **메인 영역**: 인터랙션 없음 (정적 메시지만 표시)

**권한별 UI 차이**:
- **모든 사용자**: 동일한 메시지 표시
  - 역할에 관계없이 Workspace 멤버십이 없으면 동일한 권한 없음 페이지

**화면 전환**:
- **조건**: 사이드바에서 권한 있는 페이지 선택
- **전환**: Screen 4 → Screen 2
- **전환 방식**: 메인 영역 fade-out → fade-in (150ms)

**애니메이션**:
- 메인 영역 fade-in (200ms ease-in-out)
- 아이콘 약간의 scale-in 효과 (선택사항)

**접근성**:
- **스크린 리더**:
  - role="alert" 속성으로 권한 없음 상태 즉시 알림
  - 제목에 aria-label: "페이지 접근 불가"

---

### 결과 피드백

**성공 시** (페이지 로드 완료):
- **UI 반응**: 
  - 메인 영역에 페이지 콘텐츠 표시
  - 선택된 페이지 아이템 강조 (primary-50 배경)
- **메시지**: 별도 Toast 없음 (자연스러운 전환)
- **다음 액션**: 
  - 페이지 콘텐츠 편집 가능 (Block System)
  - 다른 페이지로 이동 가능

**실패 시** (네트워크 오류, 서버 오류):
- **UI 반응**: 
  - 메인 영역에 에러 화면 표시
  - Toast 메시지 표시
- **메시지**: 
  - Toast: "페이지를 불러오는데 실패했습니다. 다시 시도해주세요."
  - Toast 타입: error (빨간색)
  - 지속 시간: 5초
- **다음 액션**: 
  - 이전 페이지 상태로 복귀 (있는 경우)
  - 재시도 버튼 제공 (선택사항)

**권한 부족** (Workspace 멤버십 없음):
- **UI 반응**: Screen 4 (권한 없음 페이지) 표시
- **메시지**: "이 페이지에 접근할 수 없습니다"
- **다음 액션**: 
  - 사이드바에서 다른 페이지 선택 가능
  - 조직 관리자에게 초대 요청 (수동, Scenario 3)

**쿠키 페이지 유효하지 않음** (첫 로드 시):
- **UI 반응**: Default Workspace의 첫 번째 페이지 자동 선택
- **메시지**: 별도 메시지 없음 (자동 처리)
- **다음 액션**: 
  - 자동 선택된 페이지 표시
  - 쿠키에 새 페이지 ID 저장

## 📱 반응형 고려사항

### 데스크톱 (> 1024px)

**레이아웃**:
- 사이드바: 고정 너비 280px, 항상 표시
- 메인 영역: 나머지 공간 (flex-1)
- 페이지 캔버스 여백: 좌우 96px

**인터랙션**:
- 호버 효과 활성화
- 마우스 클릭 인터랙션
- Chevron 클릭으로 접기/펼치기

**특이사항**:
- 사이드바 스크롤: 독립적으로 스크롤 가능 (overflow-y: auto)
- 메인 영역 스크롤: 독립적으로 스크롤 가능

### 태블릿 (768px ~ 1024px)

**레이아웃**:
- 사이드바: 고정 너비 240px (데스크톱보다 좁음)
- 메인 영역: 나머지 공간
- 페이지 캔버스 여백: 좌우 48px (축소)

**인터랙션**:
- 터치 영역 확대: 최소 44x44px (iOS 가이드라인)
- 호버 효과 유지 (태블릿도 마우스 사용 가능)

**특이사항**:
- 폰트 크기 유지 (데스크톱과 동일)
- 페이지 아이템 패딩 약간 증가 (터치 영역)

### 모바일 (< 768px)

**레이아웃**:
```
[햄버거 메뉴]  [조직명]
├─────────────────────────────────────┤
│                                     │
│  [페이지 콘텐츠 - 전체 화면]         │
│                                     │
└─────────────────────────────────────┘
```

- **사이드바**: 기본적으로 숨김, 햄버거 메뉴로 토글
  - 열림: 전체 화면 오버레이 (backdrop)
  - 닫힘: 화면 왼쪽으로 슬라이드 아웃

- **메인 영역**: 전체 화면 (width: 100%)
- **페이지 캔버스 여백**: 좌우 16px (최소)

**인터랙션**:
- **햄버거 메뉴 버튼**: 
  - 헤더 왼쪽 상단
  - 클릭 시 사이드바 슬라이드 인
  
- **사이드바 열림 상태**:
  - 전체 화면 오버레이 (backdrop: rgba(0,0,0,0.5))
  - 왼쪽에서 슬라이드 인 (300ms ease-out)
  - backdrop 클릭 → 사이드바 닫기
  - ESC 키 → 사이드바 닫기
  
- **페이지 선택**:
  - 페이지 클릭 → 사이드바 자동 닫기
  - 메인 영역에 페이지 표시

- **터치 제스처**:
  - 오른쪽 스와이프 (화면 왼쪽 가장자리에서) → 사이드바 열기
  - 왼쪽 스와이프 (사이드바에서) → 사이드바 닫기

**특이사항**:
- **사이드바 너비**: 전체 화면의 80% (최대 320px)
- **헤더 조정**:
  - 조직 선택 드롭다운: 조직명만 표시 (드롭다운 아이콘 축소)
- **페이지 제목**: text-xl → text-lg (폰트 크기 축소)
- **페이지 아이템**: 
  - 패딩 증가 (터치 영역: 최소 44px 높이)
  - 폰트 크기 유지 또는 약간 증가 (가독성)

**애니메이션** (모바일 전용):
- 사이드바 슬라이드 인/아웃: 300ms ease-out
- backdrop fade-in/out: 200ms ease-in-out
