# User Flow: Block Management Domain

## 🎯 개요

**도메인**: Block Management Domain  
**작성자**: UX/UI 디자이너 + 기획자  
**작성일**: 2025-10-19  
**버전**: v1.0

**Process Model 참조**: `02-process-model.md`  
**다음 단계**: `04-technical-specification.md`

---

### 문서 목적

이 문서는 Block Management Domain의 사용자 여정을 정의합니다.  
Process Model의 비즈니스 프로세스를 기반으로 실제 화면 흐름과 사용자 인터랙션을 상세히 설명합니다.

**범위**:
- 블록 생성 및 관리 사용자 화면 흐름 정의
- 블록 타입 선택 UI 컴포넌트 및 인터랙션 명세
- 블록 편집 및 삭제 UI 정의
- 권한별 UI 차이 정의
- 에러 처리 및 피드백 방법

**제외 사항** (Frontend Specification에서 다룸):
- React 컴포넌트 구현 상세
- 상태 관리 방법 (Block State ↔ DB)
- Server Actions 연동

## 📍 Scenario 0: Block 생성 및 관리

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 0 in `02-process-model.md`
- **사용자 목표**: 새로운 블록을 생성하고 편집하여 콘텐츠를 작성하고 싶어함
- **주요 제약**: 블록 타입별 검증, 워크스페이스 권한 확인, 메타데이터 스키마 검증

---

### Screen 1: 블록 타입 선택 다이얼로그

**화면 구성**:
- **도구바**: 플러스(+) 버튼
- **블록 타입 선택 다이얼로그**: 모달 형태로 표시
- **배경 오버레이**: 클릭 시 다이얼로그 닫기

**UI 컴포넌트**:
- **플러스 버튼** (Block Management 도구바):
  - 클릭 시 블록 타입 선택 다이얼로그 표시
  - 워크스페이스 권한에 따른 활성화/비활성화 상태
- **블록 타입 선택 다이얼로그**:
  - 카테고리별 블록 타입 목록 (text, image, code, page, shape, todo)
  - 각 타입에 아이콘과 이름 표시
  - 블록 타입별 설명 텍스트
  - 검색 기능 (타입별 검색)
  - 취소/선택 버튼
- **블록 타입 카드**:
  - 타입 아이콘, 이름, 설명
  - 호버 시 하이라이트 효과
  - 선택 가능 상태 표시

**권한별 UI 차이**:
- **워크스페이스 관리자**:
  - 모든 블록 타입 생성 가능
  - 모든 옵션 활성화
  
- **워크스페이스 편집자**:
  - 일부 블록 타입만 생성 가능 (권한에 따라 필터링)
  - 제한된 옵션 표시
  
- **워크스페이스 뷰어**:
  - 플러스 버튼 비활성화
  - "읽기 전용 모드" 툴팁 표시

**인터랙션**:
- 플러스 버튼 클릭 → 블록 타입 선택 다이얼로그 표시
- 블록 타입 카드 클릭 → 타입 선택, 다이얼로그 닫기
- ESC 키 또는 배경 클릭 → 다이얼로그 닫기, 선택 취소
- 검색 입력 → 타입 목록 필터링

**화면 전환**:
- **조건**: 블록 타입 선택 완료
- **전환**: Screen 1 → Screen 2 (블록 생성 및 편집)
- **전환 방식**: 다이얼로그 닫기, 새 블록 생성 시작

---

### Screen 2: 블록 생성 및 편집

**화면 구성**:
- **블록 편집 패널**: 새로 생성된 블록의 편집 UI
- **메타데이터 설정**: 블록 타입별 속성 설정
- **저장/취소 버튼**: 변경사항 저장 또는 취소

**UI 컴포넌트**:
- **블록 기본 정보**:
  - 블록 ID (읽기 전용, 시스템 생성)
  - 워크스페이스 정보 (읽기 전용)
  - 생성 시각 (읽기 전용)
- **블록 타입 설정**:
  - 타입 선택 드롭다운 (변경 가능)
  - 타입 변경 시 메타데이터 스키마 재검증
- **메타데이터 편집기**:
  - 블록 타입별 맞춤형 편집 UI
  - JSON 스키마 검증 실시간 표시
  - 유효성 검증 오류 메시지 표시
- **저장 버튼**:
  - 변경사항이 있을 때만 활성화
  - 저장 중 로딩 인디케이터 표시

**권한별 UI 차이**:
- **관리자/편집자**:
  - 모든 필드 편집 가능
  - 타입 변경 권한 있음
  
- **뷰어**:
  - 모든 필드 읽기 전용
  - 편집 버튼 숨김

**인터랙션**:
- 블록 타입 변경 → 메타데이터 스키마 검증 및 UI 업데이트
- 메타데이터 입력 → 실시간 유효성 검증 표시
- 저장 버튼 클릭 → 변경사항 저장 및 성공 피드백
- 취소 버튼 클릭 → 변경사항 취소, 생성 중인 블록 삭제

**화면 전환**:
- **조건**: 블록 저장 완료
- **전환**: Screen 2 → Screen 3 (생성 완료 피드백)
- **전환 방식**: 성공 메시지 표시, 편집 패널 닫기

---

### Screen 3: 블록 생성 완료 피드백

**화면 구성**:
- **성공 메시지**: 블록 생성 완료 알림
- **생성된 블록 정보**: 새로 생성된 블록의 요약 정보
- **다음 액션**: 추가 편집 또는 목록으로 돌아가기

**UI 컴포넌트**:
- **생성된 블록 카드**:
  - 블록 타입 아이콘과 이름
  - 생성 시각
  - 바로 편집 링크

**인터랙션**:
- Toast 메시지 자동 사라짐 → 정상 화면으로 복귀
- "편집 계속하기" 클릭 → Screen 2로 복귀
- "목록 보기" 클릭 → 블록 목록 화면으로 이동

---

### 에러 처리

**블록 생성 실패**:
- **UI 반응**: 에러 Toast 메시지 표시, 생성 중인 블록 롤백
- **메시지**: "블록 생성에 실패했습니다: [구체적 오류 메시지]"
- **다음 액션**: 사용자가 다시 시도 가능

**타입 변경 실패**:
- **UI 반응**: 타입 변경 취소, 기존 타입으로 복원
- **메시지**: "해당 타입으로 변경할 수 없습니다: [메타데이터 호환성 오류]"

**권한 부족**:
- **UI 반응**: 블록 타입 선택 비활성화, 권한 안내 툴팁
- **메시지**: "이 블록 타입을 생성할 권한이 없습니다"

**메타데이터 검증 실패**:
- **UI 반응**: 실시간 오류 표시, 저장 버튼 비활성화
- **메시지**: "입력한 메타데이터 형식이 올바르지 않습니다"

## 📍 Scenario 1: 블록 정보 업데이트

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 0 - Sequence 2 in `02-process-model.md`
- **사용자 목표**: 기존 블록의 정보를 수정하고 업데이트하고 싶어함
- **주요 제약**: 수정 권한 확인, 메타데이터 스키마 재검증, 변경 이력 기록

---

### Screen 1: 블록 편집 요청

**화면 구성**:
- **블록 목록**: 편집할 블록이 포함된 목록
- **편집 버튼**: 블록별 편집 액션
- **권한 표시**: 블록별 편집 권한 상태

**UI 컴포넌트**:
- **블록 목록 아이템**:
  - 블록 ID, 타입, 생성/수정 시각
  - 편집 권한 상태 배지
  - 편집 버튼 (권한 있는 경우에만 활성화)
- **편집 버튼**:
  - 아이콘 버튼 (연필 아이콘)
  - 호버 시 "편집" 툴팁
  - 권한 없는 경우 비활성화

**권한별 UI 차이**:
- **소유자/관리자**:
  - 모든 블록 편집 가능
  - 편집 버튼 활성화
  
- **편집자**:
  - 본인이 생성한 블록만 편집 가능
  - 제한된 편집 권한 표시
  
- **뷰어**:
  - 편집 버튼 숨김 또는 비활성화
  - "읽기 전용" 표시

**인터랙션**:
- 편집 버튼 클릭 → Screen 2로 전환
- 블록 아이템 클릭 → 블록 상세 정보 표시
- 권한 없는 블록 클릭 → 권한 안내 메시지

**화면 전환**:
- **조건**: 편집 버튼 클릭
- **전환**: Screen 1 → Screen 2 (블록 편집 화면)
- **전환 방식**: 페이지 전환 또는 모달 오버레이

---

### Screen 2: 블록 정보 편집

**화면 구성**:
- **블록 기본 정보**: 읽기 전용 정보 표시
- **편집 가능 필드**: 수정할 수 있는 필드들
- **메타데이터 편집기**: 블록 타입별 속성 편집
- **저장/취소 버튼**: 변경사항 저장 또는 취소

**UI 컴포넌트**:
- **읽기 전용 정보**:
  - 블록 ID (시스템 생성, 변경 불가)
  - 워크스페이스 ID (소속 워크스페이스)
  - 생성 시각 (original creation time)
- **편집 가능 필드**:
  - 블록 타입 (변경 가능, 스키마 재검증 필요)
  - 메타데이터 JSON (블록 타입별 맞춤형 편집)
  - 수정 시각은 자동 갱신 (사용자 입력 불가)
- **변경 이력 표시**:
  - 이전 수정 시각들
  - 변경된 필드 히스토리

**인터랙션**:
- 블록 타입 변경 → 메타데이터 스키마 재검증
- 메타데이터 수정 → 실시간 유효성 검증
- 저장 버튼 클릭 → 변경사항 저장, 타임스탬프 업데이트
- 취소 버튼 클릭 → 변경사항 취소, 원본 상태 복원

**화면 전환**:
- **조건**: 저장 완료
- **전환**: Screen 2 → Screen 3 (업데이트 완료)
- **전환 방식**: 성공 메시지 표시

---

### Screen 3: 블록 업데이트 완료

**화면 구성**:
- **성공 피드백**: 업데이트 완료 알림
- **변경된 정보**: 업데이트된 블록 정보 요약

- **업데이트된 정보**:
  - 변경된 필드들 하이라이트
  - 이전 값과 새 값 비교 표시

**인터랙션**:
- 토스트 자동 사라짐 → 정상 화면으로 복귀
- "계속 편집" → Screen 2 유지

## 📍 Scenario 2: 블록 복제

### 비즈니스 컨텍스트

- **Process Model 참조**: 블록 생성 시나리오 재사용 + 복제 로직
- **사용자 목표**: 기존 블록을 복사해서 새로운 블록을 빠르게 생성하고 싶어함
- **주요 제약**: 원본 블록의 메타데이터 복사, 새로운 ID 생성, 복제 권한 확인

---

### Screen 1: 블록 복제 시작

**화면 구성**:
- **복제 대상 블록**: 복제할 원본 블록 선택
- **복제 액션**: 복제 버튼 또는 메뉴 옵션
- **복제 옵션**: 복제 방식 설정 (선택사항)

**UI 컴포넌트**:
- **블록 목록 아이템**:
  - 복제 가능한 블록 표시
  - 복제 버튼 또는 "복제" 메뉴 옵션
  - 복제 권한 상태 표시
- **복제 버튼**:
  - 카피 아이콘 또는 "복제" 텍스트 버튼
  - 호버 시 "복제" 툴팁
  - 권한 확인 후 활성화/비활성화

**권한별 UI 차이**:
- **관리자/편집자**:
  - 모든 블록 복제 가능
  - 복제 버튼 활성화
  
- **뷰어**:
  - 복제 버튼 비활성화 또는 숨김
  - "읽기 전용" 표시

**인터랙션**:
- 복제 버튼 클릭 → 복제 확인 또는 바로 복제
- 복제 진행 중 로딩 인디케이터 표시
- 복제 완료 후 새 블록으로 자동 이동

**화면 전환**:
- **조건**: 복제 완료
- **전환**: Screen 1 → Screen 2 (복제된 블록 편집)
- **전환 방식**: 새 블록 생성 완료 알림

---

### Screen 2: 복제된 블록 생성 완료

**화면 구성**:
- **성공 피드백**: 복제 완료 알림
- **복제된 블록**: 새로 생성된 블록 정보
- **편집 옵션**: 즉시 편집 또는 목록으로 복귀

**UI 컴포넌트**:
- **복제 완료 메시지**:
  - "블록이 성공적으로 복제되었습니다"
  - 원본 블록 ID와 새 블록 ID 표시
- **복제된 블록 카드**:
  - 새 블록 ID, 타입, 복제 시각
  - 원본 블록 정보 참조 링크
- **액션 버튼들**:
  - "지금 편집" 버튼 (새 블록 편집 화면으로)
  - "목록 보기" 버튼 (블록 목록으로 복귀)

**인터랙션**:
- "지금 편집" 클릭 → 복제된 블록 편집 화면으로 이동
- "목록 보기" 클릭 → 블록 목록에서 새 블록 확인 가능

**애니메이션**:
- 복제 완료 메시지: 300ms 페이드 인
- 새 블록 카드 등장: 200ms scale-up 효과

---

### 에러 처리

**복제 권한 부족**:
- **UI 반응**: 복제 버튼 비활성화, 권한 안내
- **메시지**: "이 블록을 복제할 권한이 없습니다"

**복제 실패**:
- **UI 반응**: 원본 블록 선택 상태 유지, 에러 메시지
- **메시지**: "블록 복제에 실패했습니다: [구체적 오류]"

**워크스페이스 제한 초과**:
- **UI 반응**: 복제 차단, 제한 안내
- **메시지**: "워크스페이스의 블록 개수 제한에 도달했습니다"

## 📍 Scenario 3: 블록 삭제 (소프트 삭제)

### 비즈니스 컨텍스트

- **Process Model 참조**: Scenario 0 - Sequence 3 in `02-process-model.md`
- **사용자 목표**: 더 이상 필요없는 블록을 삭제하고 정리하고 싶어함
- **주요 제약**: 소프트 삭제 (deleted_at 설정), 삭제 권한 확인, 복구 가능

---

### Screen 1: 블록 삭제 요청

**화면 구성**:
- **삭제 대상 블록**: 삭제할 블록이 선택된 상태
- **삭제 액션**: 삭제 버튼 또는 메뉴 옵션
- **삭제 확인**: 삭제 전 확인 다이얼로그

**UI 컴포넌트**:
- **블록 목록 아이템**:
  - 삭제 권한 표시 배지
  - 삭제 버튼 (휴지통 아이콘 또는 "삭제" 텍스트)
  - 위험 액션임을 나타내는 빨간색 강조
- **삭제 확인 다이얼로그**:
  - "블록 삭제 확인" 제목
  - 삭제 대상 블록 정보 표시
  - 소프트 삭제 안내 메시지
  - "삭제" (빨간색) / "취소" 버튼

**권한별 UI 차이**:
- **소유자/관리자**:
  - 모든 블록 삭제 가능
  - 삭제 버튼 활성화
  
- **편집자**:
  - 본인이 생성한 블록만 삭제 가능
  - 제한된 삭제 권한 표시
  
- **뷰어**:
  - 삭제 버튼 숨김 또는 비활성화
  - "읽기 전용" 표시

**인터랙션**:
- 삭제 버튼 클릭 → 삭제 확인 다이얼로그 표시
- 확인 다이얼로그에서 "삭제" 클릭 → 실제 삭제 실행
- "취소" 클릭 또는 ESC → 다이얼로그 닫기

**화면 전환**:
- **조건**: 삭제 확인
- **전환**: Screen 1 → Screen 2 (삭제 처리 중)
- **전환 방식**: 로딩 상태 표시

---

### Screen 2: 블록 삭제 처리 중

**화면 구성**:
- **로딩 상태**: 삭제 처리 진행 표시
- **진행 상황**: 삭제 단계별 안내
- **취소 옵션**: 처리 중 취소 (가능한 경우)

**UI 컴포넌트**:
- **로딩 인디케이터**:
  - 스피너 또는 프로그레스 바
  - "블록을 삭제하는 중..." 메시지
- **진행 상태**:
  - 삭제 권한 확인 ✓
  - 블록 마킹 중... (진행 중)
  - 완료 대기 중...

**인터랙션**:
- 삭제 처리 완료까지 대기
- 처리 실패 시 에러 메시지 표시

**화면 전환**:
- **조건**: 삭제 처리 완료
- **전환**: Screen 2 → Screen 3 (삭제 완료)
- **전환 방식**: 성공 피드백 표시

---

### Screen 3: 블록 삭제 완료

**화면 구성**:
- **삭제 완료 알림**: 성공 메시지 및 안내
- **삭제된 블록 정보**: 삭제된 블록의 요약 정보
- **복구 옵션**: 소프트 삭제된 블록 복구 안내

**UI 컴포넌트**:
- **성공 Toast**:
  - "블록이 삭제되었습니다" 메시지
  - 소프트 삭제임을 안내하는 추가 메시지
  - 자동 사라짐 (5초 후)
- **삭제 완료 정보**:
  - 삭제된 블록 ID와 타입
  - 삭제 시각 (deleted_at)
  - 복구 가능 안내
- **복구 안내**:
  - "삭제된 블록은 복구할 수 있습니다" 메시지
  - 관리자에게 복구 요청 링크 (권한에 따라)

**인터랙션**:
- 토스트 자동 사라짐 → 정상 화면으로 복귀
- 목록에서 삭제된 블록은 표시되지 않음
- 복구 관련 안내 표시

---

### 에러 처리

**삭제 권한 부족**:
- **UI 반응**: 삭제 버튼 비활성화, 권한 안내
- **메시지**: "이 블록을 삭제할 권한이 없습니다"

**삭제 실패**:
- **UI 반응**: 원본 상태 유지, 에러 메시지 표시
- **메시지**: "블록 삭제에 실패했습니다: [구체적 오류]"

**이미 삭제된 블록**:
- **UI 반응**: 삭제 버튼 비활성화, 상태 표시
- **메시지**: "이미 삭제된 블록입니다"

## 📱 반응형 고려사항

### 데스크톱 (> 1024px)
- **레이아웃**: 
  - 사이드바에 블록 목록 표시
  - 메인 영역에 편집 패널 표시
  - 모달 다이얼로그 크기 최적화
- **인터랙션**: 
  - 마우스 호버 효과 지원
  - 키보드 단축키 지원 (ESC, Enter 등)
  - 드래그 앤 드롭 인터페이스
- **특이사항**: 
  - 복잡한 메타데이터 편집기 지원
  - 다중 블록 선택 및 일괄 작업

### 태블릿 (768px ~ 1024px)
- **레이아웃**: 
  - 블록 목록을 접을 수 있는 사이드바로 변경
  - 편집 패널을 전체 화면 오버레이로
- **인터랙션**: 
  - 터치 최적화된 버튼 크기 (최소 44px)
  - 스와이프 제스처 지원
- **특이사항**: 
  - 블록 타입 선택을 그리드 뷰로 변경

### 모바일 (< 768px)
- **레이아웃**: 
  - 블록 목록을 하단 시트나 전체 화면으로
  - 편집 화면을 전체 화면 모달로
  - 블록 타입 선택을 스크롤 가능한 리스트로
- **인터랙션**: 
  - 터치 친화적 인터페이스
  - 롱프레스 컨텍스트 메뉴
- **특이사항**: 
  - 메타데이터 편집을 단계별 위저드 형태로
  - 백 버튼과 명확한 네비게이션

### Technical Specification
이 User Flow를 기반으로 프론트엔드 개발자는 다음 작업을 수행합니다:

1. **React 컴포넌트 설계**: 
   - BlockTypeSelector: 블록 타입 선택 다이얼로그
   - BlockEditor: 블록 편집 패널
   - BlockList: 블록 목록 컴포넌트

2. **Custom Hooks 설계**: 
   - `useBlockManagement`: 블록 CRUD 로직
   - `useBlockTypes`: 블록 타입 관리
   - `useMetadataValidation`: 메타데이터 검증

3. **상태 관리**: 
   - 블록 목록 상태 관리
   - 편집 중인 블록 상태 관리
   - 권한 상태 관리

4. **Server Actions 연동**: 
   - 블록 생성/수정/삭제 작업
   - 권한 검증 및 에러 처리

5. **DTO 직렬화**: 
   - 블록 도메인 모델 ↔ UI 데이터 변환
