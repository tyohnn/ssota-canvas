## xbowl 랜딩페이지 기획안 (Landing Page Plan)

참고: 섹션 구성과 흐름은 Railway의 랜딩페이지 구조를 레퍼런스하여 재해석함. 참고 링크: [Railway](https://railway.com/)

핵심 레퍼런스 문서: `docs/canvas-domain-architecture.md`, `docs/analyst/project-brief.md`, `docs/analyst/market-research.md`, `docs/analyst/competitor-analysis.md`, `docs/domains/`

---

### 0) 톤앤매너 / 키 메시지

- **포지셔닝**: "Scratch for AI agents" — 누구나 시각적으로 AI 에이전트 팀을 설계하고 실행하는 캔버스.
- **핵심 가치**: 시각적 설계(2D 캔버스) + 자연어 정의 + 보편 노드 시스템(Universal Node System) + 실행 모니터링(Execution Canvas).
- **핵심 전환(CTA)**: 무료로 시작, 데모 보기, 템플릿 둘러보기.

---

### 1) 헤더/히어로 (Hero)

- **헤드라인**: `ai canvas for [vibe coder]`
  - 대괄호 롤링: vibe coder → Cursor → Claude Code → Content Creator → Founder → Indie Hacker → Student → Agency
- **서브카피(2줄)**:
  - "AI 에이전트 팀 설계는 어렵습니다. 시각적 캔버스로는 쉽습니다."
  - "xbowl은 누구나 드래그앤드롭으로 에이전트·태스크·워크플로우를 연결하고, 자연어만으로 실행 가능한 팀을 만듭니다."
- **주요 CTA**: `무료로 시작하기` / `데모 영상 보기`
- **보조 CTA**: `템플릿 둘러보기`
- **보조 카피(짧은 증명)**: "설계·실행 일원화 | 템플릿 기반 확장 | 실시간 시각화"
- **비주얼 제안**: React Flow 기반 2D 캔버스 애니메이션. 노드가 점차 생성되고 엣지로 연결되며, 우측에 실행 패널이 실시간 상태를 보여주는 모션.
- **신뢰 배지/간단 로고 월(optional)**: "Built with Next.js, Supabase, Vercel AI SDK" 아이콘 나열.

---

### 2) 핵심 가치 제안 (Value Proposition)

- **섹션 타이틀**: "에이전트 팀을, 시각적으로 설계하고 실행하세요"
- **설명 문단(예시 카피)**:
  - "복잡한 오케스트레이션 없이, 시각적 캔버스에서 에이전트·태스크를 연결하고 자연어로 규칙을 정의하세요. xbowl은 동일한 데이터 모델을 기반으로 설계와 실행을 하나의 경험으로 제공합니다."
- **포인트 카드**:
  1. **Visual 2D Canvas**: 드래그앤드롭으로 워크플로우 구성. 공통 스키마(`blocks`, `edges`, `block_positions`)로 일관성 유지.
  2. **Universal Node System**: 모든 것을 노드로 통합(설계/실행 일관성). 템플릿 기반 커스텀 타입 지원.
  3. **Dual Canvas**: 디자인 모드와 실행 모드 분리. 설계-실행 전환이 즉시.
  4. **Natural Language Definition**: 자연어로 에이전트·태스크 정의, 실행 가능한 설정으로 변환.
  5. **Artifact Transparency**: 실행 산출물(아티팩트) 중심의 협업과 평가.

---

### 3) 제품 기둥(Pillars) — Railway의 Deploy/Network/Scale/Monitor/Evolve 맵핑

- **섹션 타이틀**: "Design · Connect · Execute · Monitor · Evolve"
- **5열 카드(아이콘 + 한 줄 헤드 + 2~3줄 본문)**:
  1. **Design**: 에이전트/태스크/템플릿을 시각적으로 배치하고 속성을 편집합니다.
  2. **Connect**: 입력/출력/다음 단계/포함 관계를 엣지로 연결하여 데이터 흐름과 순서를 정의합니다.
  3. **Execute**: 실행 모드에서 실시간 진행 상황을 캔버스 위에 즉시 렌더링합니다(프로그레시브 노드 생성).
  4. **Monitor**: 상태, 로그, 산출물을 패널에서 확인하고 필요 시 개입합니다.
  5. **Evolve**: 평가/수정/버전업으로 템플릿과 워크플로우를 지속 개선합니다.

---

### 4) 퀵스타트 / 속도 (Quickstart / Velocity)

- **타이틀**: "시작은 5분, 확장은 무한"
- **3단계 가이드**:
  1. 템플릿 선택 또는 빈 워크플로우 생성
  2. 노드 배치와 자연어 속성 정의
  3. 실행 전환과 실시간 모니터링
- **보조 카피**: 설치 없이 웹에서 바로 시작. 나중에 템플릿과 마켓플레이스로 확장.
- **비주얼**: 1-2-3 스텝 일러스트/스크린샷.

---

### 5) Build & Deploy 섹션 재해석 (Railway 레퍼런스)

- **섹션 타이틀**: "강력한 비주얼 캔버스로 에이전트 팀을 구축하고 실행하세요"
- **본문**: GitHub 리포지토리나 템플릿에서 시작해, 설계-실행-관찰-개선을 하나의 화면에서 처리합니다. (구조 차용: [Railway](https://railway.com/))
- **포인트**:
  - 설계와 실행의 단일 UI
  - 템플릿 기반 런타임 타입 생성(페이지/컴포넌트/데이터)
  - 산출물 중심 협업(문서/구조화 데이터/플로우)

---

### 6) 대체/보완 섹션 (Replaces / Complements)

- **헤드라인**: "코드 중심 도구의 장벽 없이, 시각적으로 시작"
- **리스트**:
  - Flowise, n8n 같은 툴을 보완/대체 — 비개발자도 빠르게 설계/실행
  - 복잡한 오케스트레이터 없이 자연어 + 템플릿으로 충분
  - 팀 협업에 유리한 캔버스 중심 UX
  - 비교표는 하단 경쟁 섹션 참조

---

### 7) 유스케이스/템플릿 (Use Cases & Templates)

- **섹션 타이틀**: "바로 써먹는 템플릿으로 더 빨리"
- **카테고리 카드**:
  - 개발 에이전트 팀(리서처 → 설계 → 구현 초안 → 리뷰)
  - 콘텐츠 제작(주제 리서치 → 구성 → 초안 → 편집 체크리스트)
  - 교육(수업 자료 구성 → 퀴즈 생성 → 학습 가이드)
  - 분석(시장 리서치 → 경쟁 분석 → 요약 리포트)
- **템플릿 카드 구성**: 썸네일, 주요 노드, 예상 산출물, 실행시간 범위, CTA(템플릿 사용).

---

### 8) 디벨로퍼 섹션 (For Developers)

- **헤드라인**: "개발자를 위한 확장성과 투명성"
- **포인트**:
  - Next.js 15, TypeScript 5, React Flow, Supabase + Drizzle, Clerk, Vercel AI SDK
  - Universal Node System으로 설계/실행 데이터 일관성
  - 서버 액션 기반 백엔드와 RLS 보안 모델
  - CLI/SDK(예: `xbowl-cli`)로 설정/동기화 자동화(추가 예정)
- **스니펫 아이디어**: 간단한 서버 액션 호출 또는 노드 생성 예시(문서 링크로 대체 가능)

---

### 9) 실행 가시성/관찰 가능성 (Observability)

- **헤드라인**: "보이는 실행, 믿을 수 있는 결과"
- **본문**: 실행 모드에서 노드가 점진적으로 생성되고 관계가 연결되는 과정을 그대로 시각화합니다. 산출물은 아티팩트로 남아 평가와 수정이 쉬워집니다.
- **포인트 아이콘**: 실시간 상태, 로그/트레이스, 산출물 미리보기, 버전 관리(향후), 재실행.

---

### 10) 소셜 프루프 / 추천사 (Social Proof)

- **헤드라인**: "이런 분들이 먼저 시작했습니다"
- **로고 월**: 얼리어답터/커뮤니티 아이콘(예: OSS, 개발 커뮤니티 로고 제안)
- **추천사(가이드)**: 50~80자 내외, 역할/유즈케이스/효과 중심. 실제 수집 전까지는 플레이스홀더 사용.

### 11) 경쟁 비교 (Competitive Positioning)

- **요약 표**: xbowl vs Flowise vs n8n(간단 축) — 대상 사용자, 학습 곡선, 마켓플레이스, 템플릿, 시각화 강도
- **카피**: "비개발자에게도 열려 있는, 교육 친화적인 에이전트 워크플로우 캔버스"
- **링크**: 자세한 비교는 `docs/analyst/competitor-analysis.md` 참고

### 12) 가격 (Pricing)

- **헤드라인**: "시작은 무료, 성장은 유연하게"
- **플랜 카드**:
  - Free: 기본 캔버스, 템플릿 일부, 월 1,000 토큰
  - Pro: 고급 템플릿/조회수 증가, 월 X만 토큰, 우선 지원
  - Business: 팀 협업, 더 많은 토큰, 역할/권한, 감사 로그
  - Enterprise: 커스텀 보안/배포/SLAs
- **하부 주석**: 토큰 기반 사용량 과금(세부는 `docs/analyst/market-research.md` 제안안 참조)

### 13) FAQ

- xbowl은 코딩 없이도 가능한가요?
  - 네. 시각적 캔버스와 자연어 정의만으로 기본 워크플로우를 만들고 실행할 수 있습니다.
- 복잡한 조건/반복 로직은 어떻게 처리하나요?
  - 현대 에이전트의 의미 이해 + 템플릿/규칙 설계로 커버하며, 점진적 개선을 권장합니다(`project-brief.md` 참조).
- 결과물은 어떻게 관리되나요?
  - 실행 산출물은 아티팩트로 저장/열람/평가 가능하며, 템플릿으로 일관성 있게 확장됩니다.
- 협업은 가능한가요?
  - 초기엔 단일 사용자 중심, 이후 팀 협업/리얼타임 편집을 확장할 계획입니다.
