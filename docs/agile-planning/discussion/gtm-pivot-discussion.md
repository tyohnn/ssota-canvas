# GTM 전략 피봇 논의

> 작성일: 2025.12.08  
> 배경: 출시 속도 개선을 위한 MVP 범위 재정의

---

## 1. 문제 인식

### 현재 상황

- **핸드오프 없는 전체 캔버스**를 목표로 하다 보니 제품 요구사항이 너무 커짐
- 다양한 유스케이스를 모두 다루려다 보니 블록/블록 액션/블록 앱스페이스 개발이 끝없이 늘어남
- 하나의 유스케이스를 **온전하게 개발해서 빨리 출시**하는 것이 더 중요

### 핵심 깨달음

> **"고객을 너무 늦게 만난다. 아주 작은 단위에서부터 고객을 만나야 한다."**

## 3. 쏘타의 핵심 사용 사례 정의

### 현재 쏘타를 쓰는 방법 (대표자 기준)

1. **메모, 노트**
2. **링크/유튜브/이미지 아카이빙**
3. **복잡한 것들 구조화/기획**
4. **AI와 캔버스에서 대화하고 협업하기**

### MVP에서 반드시 동작해야 하는 것

| 기능 | 설명 |
|------|------|
| ✅ AI 마크다운 블록 작성 | AI가 마크다운 블록을 직접 작성 |
| ✅ 마크다운 작성 UX | 마크다운 블록의 작성이 매우 편함 |
| ✅ AI 캔버스 이해 | AI가 캔버스를 이해하고 답변 |
| ✅ Mermaid → Canvas | AI가 mermaid를 그리면 캔버스에 구현 (블록 타입 agnostic) |
| ✅ AI 기획/구조화 | 서비스 기획과 코드 구조화를 AI와 함께 |
| ✅ 다양한 보기 | 캔버스 외 칸반, 테이블, 타임라인 보기 |

## 4. 경쟁사 대비 포지셔닝

### 쏘타의 강점 영역

```
시각화 / 구조화
AI 시각화 / 구조화
아카이빙
자동화 (특정 워크플로우)
AI와 디벨롭
커스텀 설정
```

### 경쟁사 분석

| 서비스 | 강점 | 약점 |
|--------|------|------|
| **노션** | 아카이빙, 문서 작업 | 시각화/구조화 어려움, 펼쳐놓고 조합하기 어려움 |
| **미로/피그잼** | 시각화/구조화, AI와 캔버스 | 커스텀 에이전트로 맞춤형 워크플로우 부재 |
| **ChatGPT** | 커스텀 에이전트, AI 기능 | 아카이빙 부재, 시각화/구조화 부재 |
| **아키(Archi)** | 문서 작성, 문서 구조화, 문서 변형/추출 | 다양한 데이터 지원 부족, 커스텀 에이전트 부재 |

### 쏘타의 차별점

> **노션의 정형성 + 미로의 시각화 + ChatGPT의 커스텀 에이전트**

## 8. MVP 제품 컨셉: AI Note

### 제품 정의

> **AI Note** — Intelligence Note for Knowledge Workers  
> *"Research, Organize, Create"*

AI와 함께 생각하고, 정리하고, 만들어내는 **지식 노동자를 위한 AI 노트**.

### 핵심 가치 (3가지 축)

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   Intelligent       Creative         Systemic              │
│   ───────────       ────────         ────────              │
│   맥락 파악          인사이트 생성      데이터 연결           │
│   데이터 탐색        시각화/구조화      아카이빙             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| 가치 | 핵심 기능 | 설명 |
|------|-----------|------|
| **Intelligent** | 의도/맥락 파악 | 나의 의도와 맥락을 파악하기 |
| | 데이터 탐색 | 원하는 데이터를 찾아주기 |
| **Creative** | 인사이트 생성 | 그래프, 코드, 이미지 생성 등으로 새로운 인사이트 제공 |
| | 시각화/구조화 | 복잡한 정보를 시각적으로 구조화 |
| **Systemic** | 아카이빙 | 다양한 형태의 데이터를 저장/관리 |
| | 데이터 연결 | 블록 간 관계 정의, 데이터베이스화 |

### 슬로건

```
Research → Organize → Create
   ↓          ↓          ↓
 탐색       정리        생성
```

**"One Knowledge Worker"** — AI와 함께하는 1인 지식 노동자

### 기존 컨셉과의 연결

| 기존 (SSOTA Canvas) | 신규 (AI Note) |
|---------------------|----------------|
| 핸드오프 없는 전체 캔버스 | 지식 노동자를 위한 AI 노트 |
| 모든 유스케이스 커버 | Research → Organize → Create |
| 블록/엣지/속성 | Intelligent + Creative + Systemic |

## 9. 피봇 방향 정리

### 제품 포지셔닝 변화

```
[AS-IS] SSOTA Canvas — 핸드오프 없는 범용 협업 캔버스
    ↓
[TO-BE] AI Note — 지식 노동자를 위한 AI 노트
        "Research, Organize, Create"
```

### 타겟 페르소나

> **One Knowledge Worker**  
> AI를 레버리지 삼아 리서치, 기획, 문서 작업을 혼자서도 빠르게 해내고 싶은 지식 노동자

- 바이브 코더 (비개발자 + AI로 개발)
- 1인 기획자/창업자
- 리서치가 많은 직군 (컨설턴트, 마케터, PM)
- 취준생 (자기소개서, 면접 준비)

### 핵심 원칙

1. **Intelligent First**: AI가 맥락을 이해하고 데이터를 찾아줌
2. **Creative Output**: 단순 정리가 아닌, 새로운 인사이트/산출물 생성
3. **Systemic Foundation**: 아카이빙과 데이터 연결로 지식 축적
4. **작게 시작**: 마크다운 + 도형 + 링크 3가지 블록으로 시작
5. **빠르게 출시**: 하나의 유스케이스를 온전하게 완성
