# Sprint 011: Block Management Foundation

## 🎯 Sprint 개요
**목표**: 2주 동안 블록 생성 및 기본 관리 기능을 완성하여 사용자가 블록을 생성하고 기본 정보를 관리할 수 있도록 한다

**기간**: 2025-10-22 ~ 2025-11-05 (2주)  
**팀**: 개발팀 3명  
**용량**: 120시간 (3명 × 10일 × 4시간)

## 📋 포함 Story

### Story BM-001: 블록 생성 및 기본 관리 (13pts)
**목표**: Shadow Block → Skeleton Block → Completed Block 흐름 완성  
**담당자**: 시니어 개발자  
**예상 완료일**: 2025-10-29

### Story BM-002: 블록 편집 및 정보 관리 (8pts)
**목표**: 블록 기본 정보 편집 및 타입 변경 기능 완성  
**담당자**: 주니어 개발자  
**예상 완료일**: 2025-11-01

### Story BM-003: 커스텀 속성 관리 (21pts)
**목표**: 커스텀 속성 추가/편집/삭제 및 타입별 설정 기능 완성  
**담당자**: 시니어 개발자  
**예상 완료일**: 2025-11-05

## 📅 Sprint 일정

### Week 1
- **월요일**: BM-001 블록 생성 기능 개발 시작
- **화요일**: BM-001 Shadow Block → Skeleton Block 흐름 구현
- **수요일**: BM-001 Completed Block 렌더링 구현
- **목요일**: BM-002 블록 편집 기능 개발 시작
- **금요일**: BM-002 블록 타입 변경 기능 구현

### Week 2
- **월요일**: BM-003 커스텀 속성 관리 개발 시작
- **화요일**: BM-003 속성 추가/편집 기능 구현
- **수요일**: BM-003 Field Popover 중첩 구조 구현
- **목요일**: BM-003 선택형 속성 옵션 관리 구현
- **금요일**: 통합 테스트 및 버그 수정
