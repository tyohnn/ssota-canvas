# Sprint 024: AI Features

## 🎯 Sprint 개요
**목표**: AI 리서치 툴과 정렬 기능을 구현하여 Research → Organize 워크플로우를 지원한다

**기간**: 2025-12-29 ~ 2025-12-31 (3일)  
**팀**: 개발팀  
**용량**: 24시간 (2명 × 3일 × 4시간)  
**Story Points**: 13pts

## 📋 포함 Story

### Story E008-001: AI 리서치 툴 구현 (8pts, P0)
**목표**: AI가 웹 검색으로 리서치를 수행하고 결과를 블록으로 생성하는 기능 구현  
**담당자**: 시니어 개발자  
**예상 완료일**: 2025-12-30

### Story E008-002: AI 정렬 기능 구현 (5pts, P2)
**목표**: 멀티 선택된 블록을 AI가 자동으로 정렬하는 기능 구현  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-31

### Story E008-003: 그록으로 변경 (3pts, P3, 선택적)
**목표**: AI 인프라를 그록 API로 변경  
**담당자**: 시니어 개발자  
**예상 완료일**: 2025-12-31 (선택적)
