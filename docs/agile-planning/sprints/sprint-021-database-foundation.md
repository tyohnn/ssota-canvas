# Sprint 021: Database Foundation

## 🎯 Sprint 개요
**목표**: 데이터베이스 생성/설정, 블록 편입, 테이블 뷰를 구현하여 캔버스의 블록을 정형화된 데이터로 관리할 수 있도록 한다

**기간**: 2025-12-15 ~ 2025-12-17 (3일)  
**팀**: 개발팀  
**용량**: 24시간 (2명 × 3일 × 4시간)  
**Story Points**: 21pts

## 📋 포함 Story

### Story E007-001: 데이터베이스 생성/설정 (8pts)
**목표**: 데이터베이스 생성, 설정 UI, 칼럼 관리 기능 구현  
**담당자**: 시니어 개발자  
**예상 완료일**: 2025-12-16

### Story E007-002: 블록 → 데이터베이스 편입 (8pts)
**목표**: 캔버스 블록을 데이터베이스에 편입하는 기능 구현  
**담당자**: 시니어 개발자  
**예상 완료일**: 2025-12-17

### Story E007-003: 테이블 뷰 렌더링 (5pts)
**목표**: 데이터베이스를 테이블 형태로 조회하는 뷰 구현  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-17

## 🔗 의존성 및 리스크

### 의존성
- **외부 의존성**: Supabase, Drizzle ORM
- **내부 의존성**: Epic-005 기본 블록 & 보기 시스템 (카드 보기 활용)

### 리스크
- **기술적 리스크**: 대용량 테이블 렌더링 성능 문제
  - **대응**: 가상 스크롤링 적용, 인덱싱 최적화
- **일정 리스크**: 블록 편입 로직이 예상보다 복잡할 수 있음
  - **대응**: 단계적 구현 및 우선순위 조정
