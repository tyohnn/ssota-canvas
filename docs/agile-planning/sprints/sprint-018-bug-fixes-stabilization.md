# Sprint 018: Bug Fixes & Stabilization

## 🎯 Sprint 개요
**목표**: 알려진 버그를 수정하여 안정적이고 버그 없는 시스템을 제공한다

**기간**: 2025-12-04 ~ 2025-12-10 (1주)  
**팀**: 개발팀  
**용량**: 40시간 (2명 × 5일 × 4시간)  
**Story Points**: 8pts

## 📋 포함 Story

### Story E011-001: 윈도우 패닝/줌 감도 조정 (1pt)
**목표**: 윈도우에서 패닝/줌 감도가 정상적으로 동작하도록 수정  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-05

### Story E011-002: 스페이스바 이동 버그 수정 (3pts)
**목표**: 스페이스바로 이동한 후 선택도구 툴바가 정상 동작하도록 수정  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-07

### Story E011-003: 멀티셀렉 문제 해결 (5pts)
**목표**: 멀티셀렉이 정상적으로 동작하도록 수정  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-09

- **외부 의존성**: React Flow, 키보드 이벤트 처리 라이브러리
