# Sprint 020: View System Implementation

## 🎯 Sprint 개요
**목표**: 보기 방식 시스템을 구현하고 마크다운/카드 보기를 완성하여 블록을 다양한 형태로 조회할 수 있도록 한다

**기간**: 2025-12-08 ~ 2025-12-14 (1주)  
**팀**: 개발팀  
**용량**: 40시간 (2명 × 5일 × 4시간)  
**Story Points**: 18pts

## 📋 포함 Story

### Story E005-003: 보기 방식 시스템 구현 (8pts)
**목표**: ViewMode 전환 로직, 컨텍스트 메뉴/단축키 연동, 기본 보기 자동 선택, ViewMode 저장/로드 구현  
**담당자**: 시니어 개발자  
**예상 완료일**: 2025-12-12

### Story E005-004: 마크다운 보기 구현 (5pts)
**목표**: 상단 제목 표시, 한번 클릭 편집 모드, 상단 바 드래그 이동, 마크다운 렌더링 구현  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-13

### Story E005-005: 카드 보기 구현 (5pts)
**목표**: 커스텀 속성 표시, 카드 레이아웃, 속성 편집 UI, 카드 스타일링 구현  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-14
