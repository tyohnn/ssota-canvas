# Sprint 023: New Block Types

## 🎯 Sprint 개요
**목표**: 목차, 프레임, 페이지 이동 블록을 구현하여 콘텐츠 구조화 및 네비게이션 기능을 제공한다

**기간**: 2025-12-22 ~ 2025-12-28 (1주)  
**팀**: 개발팀  
**용량**: 40시간 (2명 × 5일 × 4시간)  
**Story Points**: 13pts

## 📋 포함 Story

### Story E006-001: 목차 블록 구현 (5pts)
**목표**: 목차 블록 생성, 자동 업데이트, 클릭 네비게이션 기능 구현  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-24

### Story E006-002: 프레임 블록 구현 (5pts)
**목표**: 프레임 블록 생성, 블록 그룹화, 단위 이동/복사/삭제 기능 구현  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-26

### Story E006-003: 페이지 이동 블록 구현 (3pts)
**목표**: 페이지 이동 블록 생성, 페이지 이동, 미리보기 기능 구현  
**담당자**: Frontend Developer  
**예상 완료일**: 2025-12-28

### Week 1
- **월요일 (12-22)**:

- **화요일 (12-23)**: 
  - E006-001 목차 생성 로직 구현

- **수요일 (12-24)**: 
  - E006-001 목차 클릭 네비게이션 구현
  - E006-001 완료 검증
  - E006-002 프레임 블록 타입 정의 시작
- **목요일 (12-25)**: 
  - 휴일
- **금요일 (12-26)**: 
  - E006-002 프레임 컨테이너 구현
  - 프레임 단위 이동/복사/삭제 로직 구현
  - E006-002 완료 검증
- **일요일 (12-28)**: 
  - E006-003 페이지 이동 블록 구현 완료
  - 페이지 미리보기 구현
  - 전체 통합 테스트 및 회고
