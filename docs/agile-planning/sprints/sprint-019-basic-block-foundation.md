# Sprint 019: Basic Block Foundation

## 🎯 Sprint 개요
**목표**: 기본 블록 아키텍처를 설계하고 마크다운 블록을 마이그레이션하여 확장 가능한 블록 시스템의 기반을 구축한다

**기간**: 2025-12-08 ~ 2025-12-14 (1주)  
**팀**: 개발팀  
**용량**: 40시간 (2명 × 5일 × 4시간)  
**Story Points**: 21pts

## 📋 포함 Story

### Story E005-001: 기본 블록 정의 및 아키텍처 설계 (13pts)
**목표**: 기본 블록 타입, ViewMode 타입, 기본 보기 매핑 정의 및 마이그레이션 스키마 설계  
**담당자**: 시니어 개발자 + 주니어 개발자  
**예상 완료일**: 2025-12-12

### Story E005-002: 마크다운 블록 마이그레이션 (8pts)
**목표**: 기존 마크다운 블록을 기본 블록으로 변환하는 마이그레이션 스크립트 작성 및 실행  
**담당자**: 시니어 개발자  
**예상 완료일**: 2025-12-14

- **목요일 (12-11)**:
