# Epic-007: Database Feature - Table View

## 🎯 Epic 개요
**Epic Goal**: As a 사용자, I want to 캔버스의 블록을 데이터베이스에 편입하고 테이블 뷰로 조회하여 so that 정형화된 데이터로 관리할 수 있다

**기간**: 2025-12-22 ~ 2025-12-31 (1.5주, 1-2 Sprints)  
**Story Points**: 21pts (예상)  
**우선순위**: High (P0)  
**현재 상태**: 📋 계획 중

## 📊 비즈니스 가치

### 문제 정의
1. **컴포넌트/인스턴스 한계**: 
   - 하나의 컴포넌트는 단일 블록 타입만 가질 수 있음
   - 여러 종류의 블록을 하나의 데이터베이스에 포함할 수 없음

2. **정형화 부재**: 
   - 캔버스의 블록을 테이블 형태로 볼 수 없음
   - 데이터베이스 뷰(테이블, 칸반 등)가 없음

3. **데이터 관리 어려움**: 
   - 블록을 데이터로 관리하기 어려움
   - 검색 및 필터링이 제한적

### 해결책
1. **데이터베이스 시스템**: 
   - 컴포넌트/인스턴스를 데이터베이스로 대체
   - 하나의 데이터베이스에 다양한 블록 타입 포함 가능

2. **블록 편입 기능**: 
   - 캔버스의 블록을 데이터베이스에 편입
   - 기존 데이터베이스에 블록 추가 가능

3. **테이블 뷰**: 
   - 데이터베이스를 테이블 형태로 조회
   - 블록 속성을 칼럼으로 표시

### 기대 효과
- ✅ **유연한 데이터 관리**: 다양한 블록 타입을 하나의 데이터베이스에서 관리
- ✅ **정형화된 뷰**: 테이블 뷰로 데이터를 구조화하여 조회
- ✅ **검색 및 필터링**: 데이터베이스 기능으로 강력한 검색/필터링

- **Row Management**: 행 추가/삭제/편집
- **Filter & Sort**: 필터링 및 정렬 기능
