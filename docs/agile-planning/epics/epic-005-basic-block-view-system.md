# Epic-005: Basic Block & View System - Card/Markdown Views

## 🎯 Epic 개요
**Epic Goal**: As a 사용자, I want to 마크다운 블록을 기본 블록으로 대체하고 모든 블록에 카드/마크다운 보기 방식을 제공받아 so that 블록을 다양한 형태로 조회하고 관리할 수 있다

**기간**: 2025-12-01 ~ 2025-12-14 (2주, 1-2 Sprints)  
**Story Points**: 34pts (예상)  
**우선순위**: High (P0)  
**현재 상태**: 📋 계획 중

## 📊 비즈니스 가치

### 문제 정의
1. **마크다운 블록의 한계**: 
   - 마크다운 블록이 특정 블록 타입으로 고정되어 있음
   - 다른 블록 타입에서 마크다운 콘텐츠를 보기 어려움
   - 블록 타입과 보기 방식이 강하게 결합되어 있음

2. **보기 방식 부재**: 
   - 블록을 정형화된 형태(카드)로 볼 수 없음
   - 커스텀 속성을 시각적으로 확인하기 어려움
   - 데이터베이스 뷰와 연동하기 어려움

3. **확장성 부족**:
   - 새로운 보기 방식을 추가하기 어려움
   - 블록 타입별로 다른 렌더링 로직이 분산되어 있음

### 해결책
1. **기본 블록 아키텍처**: 
   - 마크다운 블록을 기본 블록으로 대체
   - 모든 블록이 기본 블록을 상속받아 확장 가능한 구조
   - 블록 타입과 보기 방식을 분리

2. **보기 방식 시스템**: 
   - 모든 블록에 `viewMode` 속성 추가: `'default' | 'card' | 'markdown'`
   - 블록 타입별 기본 보기 자동 선택
   - 사용자가 보기 방식 전환 가능

3. **마크다운/카드 보기 구현**:
   - 마크다운 보기: 콘텐츠 중심 표시, 상단 제목, 한번 클릭 수정
   - 카드 보기: 커스텀 속성 중심 표시, 구조화된 UI

### 기대 효과
- ✅ **유연한 블록 관리**: 블록을 다양한 형태로 조회 가능
- ✅ **데이터베이스 연동**: 카드 보기로 데이터베이스 뷰와 자연스럽게 연동
- ✅ **사용자 경험 개선**: 블록 타입에 맞는 최적의 보기 방식 제공
- ✅ **확장성 향상**: 새로운 보기 방식 추가 용이

## 🎯 성공 기준

### 기능적 기준
- [ ] **기본 블록 정의**: 새로운 블록 아키텍처 설계 및 구현 (E005-001)
- [ ] **마크다운 블록 마이그레이션**: 기존 마크다운 블록을 기본 블록으로 변환 (E005-002)
- [ ] **보기 방식 시스템**: `viewMode` 속성 및 전환 시스템 구현 (E005-003)
- [ ] **마크다운 보기**: 상단 제목, 한번 클릭 수정, 상단 바 이동 (E005-004)
- [ ] **카드 보기**: 커스텀 속성 표시 UI 구현 (E005-005)

### 성능 기준
- [ ] **보기 전환 속도**: 보기 방식 전환 < 100ms
- [ ] **렌더링 성능**: 100개 블록 동시 렌더링 60fps 유지
- [ ] **마이그레이션 시간**: 기존 데이터 마이그레이션 < 5분

### 사용성 기준
- [ ] **직관적인 전환**: 컨텍스트 메뉴 또는 단축키로 보기 전환 가능
- [ ] **마크다운 편집**: 한번 클릭으로 편집 모드 진입
- [ ] **카드 속성 표시**: 커스텀 속성을 명확하게 표시

### 품질 기준
- [ ] **단위 테스트 커버리지 80% 이상**: Block Domain Services
- [ ] **통합 테스트 통과**: 보기 전환 및 마이그레이션 검증
- [ ] **E2E 테스트 통과**: 사용자 시나리오 전체 검증
- [ ] **데이터 무결성**: 마이그레이션 후 데이터 손실 없음

## 📋 포함 기능

### 핵심 기능
- **Basic Block Aggregate**: 기본 블록 엔티티 및 값 객체
- **View Mode System**: 보기 방식 관리 시스템
- **Markdown View Component**: 마크다운 보기 렌더링
- **Card View Component**: 카드 보기 렌더링
- **Migration Service**: 마크다운 블록 → 기본 블록 마이그레이션

### 지원 기능
- **View Mode Selector**: 보기 방식 전환 UI
- **Markdown Editor**: 상단 제목, 한번 클릭 수정, 상단 바 이동
- **Card Property Display**: 커스텀 속성 표시 컴포넌트
- **Default View Mapping**: 블록 타입별 기본 보기 매핑

### 통합 기능
- **Block Management Domain 연동**: 기존 블록 시스템과 통합
- **Database View 연동**: 카드 보기와 데이터베이스 뷰 연동 준비
- **Editor Panel 연동**: 에디터 패널에서 보기 방식 설정
