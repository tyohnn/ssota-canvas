# Epic-009: Sharing & Templates - Page/Block Share, Template Save

## 🎯 Epic 개요
**Epic Goal**: As a 사용자, I want to 캔버스를 템플릿으로 저장하고 페이지/블록을 공유하여 so that 워크플로우를 재사용하고 협업할 수 있다

**기간**: 2025-12-29 ~ 2026-01-12 (2주, 1-2 Sprints)  
**Story Points**: 21pts (예상)  
**우선순위**: Medium (P1)  
**현재 상태**: 📋 계획 중

## 📊 비즈니스 가치

### 문제 정의
1. **워크플로우 재사용 불가**: 
   - 비슷한 작업을 매번 처음부터 시작해야 함
   - 성공한 워크플로우를 저장하고 재사용할 수 없음

2. **공유 기능 부재**: 
   - 다른 사용자와 페이지를 공유하기 어려움
   - 특정 블록을 직접 공유할 수 없음

3. **온보딩 어려움**: 
   - 새 사용자가 시작하기 어려움
   - 예시 템플릿이 없음

### 해결책
1. **템플릿 시스템**: 
   - 캔버스를 템플릿으로 저장
   - 템플릿을 적용하여 새 캔버스 생성

2. **공유 기능**: 
   - 페이지 공유 링크 생성
   - 블록 선택 상태로 공유 링크 생성

3. **온보딩 템플릿**: 
   - 초기 사용자를 위한 기본 템플릿 제공

### 기대 효과
- ✅ **워크플로우 재사용**: 성공한 워크플로우를 템플릿으로 저장
- ✅ **협업 지원**: 페이지/블록 공유로 협업 용이
- ✅ **온보딩 개선**: 초기 사용자 경험 향상

## 📋 포함 기능

### 핵심 기능
- **Template Service**: 템플릿 저장 및 적용 서비스
- **Sharing Service**: 페이지/블록 공유 서비스
- **Onboarding Templates**: 초기 템플릿 정의

### 지원 기능
- **Template Gallery**: 템플릿 갤러리 UI
- **Share Link Generation**: 공유 링크 생성 및 관리
- **Block Selection State**: URL query params로 블록 선택 상태
