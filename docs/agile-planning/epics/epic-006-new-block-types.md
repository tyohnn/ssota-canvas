# Epic-006: New Block Types - TOC, Frame, Page Link

## 🎯 Epic 개요
**Epic Goal**: As a 사용자, I want to 목차, 프레임, 페이지 이동 블록을 사용하여 so that 콘텐츠를 구조화하고 네비게이션할 수 있다

**기간**: 2025-12-15 ~ 2025-12-21 (1주, 1 Sprint)  
**Story Points**: 13pts (예상)  
**우선순위**: Medium (P1)  
**현재 상태**: 📋 계획 중

## 📊 비즈니스 가치

### 문제 정의
1. **구조화 도구 부재**: 
   - 긴 문서나 콘텐츠를 구조화하기 어려움
   - 목차를 자동으로 생성하거나 관리할 수 없음

2. **블록 그룹화 부재**: 
   - 관련 블록들을 그룹화하여 관리하기 어려움
   - 여러 블록을 하나의 단위로 이동/복사하기 어려움

3. **페이지 네비게이션 부재**: 
   - 다른 페이지로 이동하는 블록이 없음
   - 페이지 간 연결을 시각적으로 표현하기 어려움

### 해결책
1. **목차 블록**: 
   - 문서 구조를 자동으로 생성하고 관리
   - 목차 클릭으로 해당 섹션으로 이동

2. **프레임(그룹) 블록**: 
   - 여러 블록을 하나의 프레임으로 그룹화
   - 프레임 단위로 이동, 복사, 삭제 가능

3. **페이지 이동 블록**: 
   - 다른 페이지로 이동하는 링크 블록
   - 페이지 미리보기 및 네비게이션

### 기대 효과
- ✅ **콘텐츠 구조화**: 긴 문서를 체계적으로 관리
- ✅ **블록 그룹화**: 관련 블록을 논리적으로 그룹화
- ✅ **페이지 네비게이션**: 페이지 간 연결 및 이동 용이

## 📋 포함 기능

### 핵심 기능
- **Table of Contents Block**: 목차 블록 생성 및 관리
- **Frame Block**: 블록 그룹화 및 프레임 관리
- **Page Link Block**: 페이지 이동 블록

### 지원 기능
- **TOC Auto-generation**: 콘텐츠 기반 자동 목차 생성
- **Frame Selection**: 프레임 내 블록 선택 및 편집
- **Page Preview**: 페이지 이동 블록 미리보기
