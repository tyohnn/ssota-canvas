# Project Vision & Strategy

## 🎯 프로젝트 비전
**"AI와 인간이 하나의 웹 기반 플랫폼에서 소통하며, 모든 도메인과 워크플로우를 통합 관리할 수 있는 새로운 컴퓨팅 방식"**

## 💡 핵심 아이디어

### 해결하고자 하는 문제
- **워크플로우 분산**: 현재 기획(노션) → 계획(리니어/지라) → 디자인(피그마) → 개발(코딩도구)로 분산된 비효율성
- **AI-인간 소통 단절**: AI와 인간이 소통할 수 있는 통합된 SSOT(Single Source of Truth)의 부재
- **도메인별 분화**: 각 버티컬 도메인마다 별도 소프트웨어가 필요한 현실

### 핵심 솔루션
- **블록 기반 추상화**: 노션+피그마 방식의 블록 단위 확장 (마크다운, 도형, 이미지, 비디오, GitHub 연동, 코드, LaTeX 등)
- **화이트보드 기반**: 2차원 공간에서의 자유로운 사고와 정형화 과정
- **AI 통합**: 정형적 데이터 활용으로 AI가 쉽게 읽고 작업할 수 있는 구조
- **멀티 도메인**: 서비스 개발, 홈페이지 제작, 영상 제작, 이미지 편집, 3D 렌더링, 교육 등 지원
- **워크플로우 자동화**: AI 에이전트를 직접 정의하여 워크플로우 자동화

### 첫 번째 타겟 시장
- **서비스 개발팀** (외주사/운영사)
- **전략적 근거**: 캐즘 마케팅 - 기술직군은 선각자가 실용주의자보다 많을 수 있음 (커서 성공 사례 참고)
- **Zero-to-One 접근**: 넓은 추상화 레이어 개발 후, 하나의 유스케이스부터 시장 공략

## 📊 전략적 목표 (3년)

### 2025년: Foundation & Core Platform (진행 중) 🔄
**목표**: 블록 기반 추상화 시스템 완성 및 서비스 개발팀 시장 진입
- **Q3**: 화이트보드 기반 블록 시스템 + 기본 AI 통합 🔄 (진행 중)
- **Q4**: 서비스 개발팀 타겟 완전 기능 + AI 에이전트 시스템 + 워크플로우 자동화 📋

### 2026년: Multi-Domain Expansion & Global Scale (계획 중) 📋
**목표**: 다양한 버티컬 도메인 확장 및 글로벌 스케일링
- **Q1**: 영상제작, 교육, 홈페이지 제작, 3D 도메인 확장 📋
- **Q2**: 글로벌 확장 + 아이패드/모바일 플랫폼 확장 📋
- **Q3**: 하드웨어 제작 + 새로운 컴퓨팅 패러다임 적용 공유 오피스 설계 📋
- **Q4**: 하드웨어-소프트웨어 통합 생태계 구축 📋

### 2027년: Hardware Industry & Computing Revolution (계획 중) 📋
**목표**: 하드웨어 산업 진출 및 새로운 컴퓨팅 패러다임의 물리적 구현
- 하드웨어 산업 집중 및 새로운 컴퓨팅 환경 정의
- AI-인간 협업을 위한 물리적 인터페이스 혁신
- 소프트웨어-하드웨어 통합 생태계 완성

## 🎯 핵심 차별화 포인트

### vs 기존 화이트보드/캔버스 서비스 (피그마, 미로 등)
- **블록 기반 추상화**: 피그마와 달리 다양한 블록 유형 지원 (코드, GitHub, LaTeX 등)
- **정형적 데이터 활용**: AI가 읽기 쉬운 구조화된 데이터로 자동화 가능
- **워크플로우 통합**: 디자인뿐만 아니라 제작 전체 과정 포함

### vs 노션 등 블록 기반 서비스
- **화이트보드 UI**: 2차원 공간에서의 자유로운 사고와 배치
- **다양한 보기 모드**: 화이트보드, 테이블, 칸반 등으로 변환 가능
- **AI 에이전트 통합**: 블록별 특화된 AI 툴 제공 (유튜브 요약, 이미지 생성 등)

### vs 개발 협업 도구 (리니어, 지라 등)
- **시각적 워크플로우**: 복잡한 개발 과정을 시각적으로 관리
- **AI 자동화**: 워크플로우를 AI 에이전트로 자동화 가능
- **통합 환경**: 기획부터 구현까지 한 곳에서 완료

## 🎯 핵심 가치 제안

### 서비스 개발팀 (첫 번째 타겟)
- **기획-개발 직접 연결**: 고객 요구사항을 즉시 기획 문서화하고 개발 과정과 직접 연결
- **컴포넌트 기반 디자인**: iframe 기반 컴포넌트화로 피그마 없이 바로 코드와 디자인 동시 작업
- **프로젝트 일정 통합**: 개발 과정이 프로젝트 일정과 실시간 연동되어 진행 상황 즉시 파악
- **AI 전과정 지원**: 기획부터 개발까지 모든 과정에서 AI가 생산성 향상 지원

### 장기적 비즈니스 가치
- **새로운 컴퓨팅 패러다임**: AI 시대의 새로운 인터페이스 정의
- **멀티 도메인 확장**: 다양한 버티컬 시장으로 확장 가능
- **플랫폼 생태계**: 블록과 템플릿 마켓플레이스 구축
- **글로벌 스케일**: 웹 기반으로 전 세계 동시 서비스 가능

## 🏗️ 기술 전략

### 핵심 기술 스택
- **Frontend**: Next.js (Server Actions), React Flow (화이트보드), TypeScript
- **Backend**: Next.js 풀스택 (Server Actions), Drizzle ORM
- **Database**: Supabase (PostgreSQL 기반)
- **Authentication**: Clerk (조직/계정 관리)
- **AI/ML**: OpenAI API, 블록별 특화 AI 모델
- **Infrastructure**: Vercel, Supabase Infrastructure

### 블록 시스템 우선순위
1. **기획 관련 블록**: 마크다운, 도형 블록
2. **개발 관련 블록**: 코드 블록, GitHub 연동 블록
3. **협업 기능**: 실시간 편집, 댓글, 버전 관리 (블록이 아닌 플랫폼 기능)

### 아키텍처 원칙
- **모노레포**: 마이크로서비스 대신 통합된 코드베이스로 빠른 개발
- **동기 처리**: Event-driven이지만 이벤트 버스 없이 동기적 처리로 단순화
- **컴포넌트 중심**: iframe 기반 컴포넌트화로 디자인-개발 통합
- **AI-First**: 모든 블록과 워크플로우에 AI 통합을 기본으로 설계

## 📈 성공 지표

### 2025년 목표 (서비스 개발팀 시장 진입)
- **베타 사용자**: 서비스 개발팀 1,000팀
- **핵심 기능 완성도**: 기획-개발-일정 통합 워크플로우 100% 완성
- **AI 통합도**: 모든 핵심 블록에 AI 기능 통합
- **사용자 만족도**: 기존 도구 대비 생산성 50% 향상

### 2026년 목표 (멀티 도메인 & 글로벌)
- **도메인 확장**: 영상제작, 교육, 홈페이지, 3D 각 도메인별 10,000 사용자
- **글로벌 사용자**: 전 세계 100,000 사용자 (아이패드/모바일 포함)
- **하드웨어 프로토타입**: 새로운 컴퓨팅 패러다임 적용 하드웨어 완성
- **공유 오피스**: 1개 이상의 파일럿 공유 오피스 운영

### 2027년 목표 (하드웨어 혁명)
- **하드웨어 시장**: 새로운 컴퓨팅 하드웨어 시장 창출
- **통합 생태계**: 소프트웨어-하드웨어 완전 통합 생태계 구축
- **산업 영향**: AI-인간 협업의 새로운 표준 정의
