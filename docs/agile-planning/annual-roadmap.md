# Annual Roadmap 25/26

## 📅 분기별 Initiative 로드맵

### Q3 2025: Foundation Platform Initiative (진행 중) 🔄
**목표**: 화이트보드 기반 블록 시스템 완성 및 기본 AI 통합
- **Initiative 001**: Core Whiteboard & Block System
  - Epic 001: React Flow 기반 화이트보드 엔진 - 드래그 앤 드롭과 기본 편집 기능
  - Epic 002: 기본 블록 시스템 - 마크다운, 도형 등 기초 블록 구현
  - Epic 003: 블록 속성 관리 시스템 - 블록별 속성 정의 및 관리 기능
  - Epic 004: 컴포넌트 블록 시스템 - 피그마 컴포넌트-인스턴스 방식의 블록 재사용
  - Epic 005: 컴포넌트 블록 보기 적용 - 테이블, 칸반, 캘린더 등 다양한 보기 모드
  - Epic 006: 기본 AI 통합 - OpenAI API 연동 및 기본 AI 기능

**성공 지표**:
- 화이트보드 엔진 기본 기능 완성 🔄
- 5가지 이상 블록 타입 구현 🔄
- 컴포넌트 시스템 MVP 완성 🔄

### Q4 2025: Developer Market Entry Initiative (계획 중) 📋

  - Epic 007: 개발 관련 블록 - 코드 블록, GitHub 연동 등 개발팀 특화 기능

  - Epic 010: 템플릿 시스템 - 서비스 개발팀용 프로젝트 템플릿

  - Epic 012: 실시간 협업 구조 - 팀 단위 실시간 협업 및 권한 관리

**성공 지표**:

  - Epic 013: 영상제작 특화 블록 - 영상 편집, 타임라인, 렌더링 관련 블록
  - Epic 014: 교육 특화 블록 - 강의 자료, 퀴즈, 진도 관리 관련 블록
