# Project Vision 작성 가이드

이 가이드는 주니어 PM이 **Project Vision**을 작성하는 전체 과정을 단계별로 안내합니다.

## 🎯 Project Vision이란?

**Project Vision**은 프로젝트의 최상위 전략 문서로, 3년간의 비전과 전략적 목표를 정의합니다.

### 특징
- **범위**: 전체 프로젝트의 3년 전략
- **기간**: 3년 (연간 리뷰)
- **목적**: 모든 Initiative와 Epic의 방향성 제시
- **담당자**: CTO, CEO (PM 지원)

- 연도별 목표 설정 시 정확한 타임라인 계산
- 시장 상황 및 기술 트렌드 반영

## 📋 Step 1: 프로젝트 비전 정의

### 1.1 비전 문장 작성
```
❓ 질문: "이 프로젝트가 궁극적으로 달성하고자 하는 것은 무엇인가?"
```

**비전 작성 규칙:**
- **명확성**: 한 문장으로 표현 가능한 명확한 비전
- **영감**: 팀원들에게 영감을 주는 비전
- **차별성**: 경쟁사와 차별화되는 고유한 가치
- **실현 가능성**: 3년 내 달성 가능한 현실적 비전

**비전 템플릿:**
```
"[대상 사용자]가 [핵심 가치]를 통해 [최종 목표]를 달성할 수 있는 [솔루션 유형]"
```

**예시:**
```
"모든 사용자가 직관적이고 효율적으로 시각적 디자인을 만들 수 있는 통합 플랫폼"
```

### 1.2 비전 검증
**검증 체크리스트:**
- [ ] 팀원들이 이해하기 쉬운가?
- [ ] 사용자에게 명확한 가치를 제공하는가?
- [ ] 경쟁사와 차별화되는가?
- [ ] 3년 내 달성 가능한가?
- [ ] 측정 가능한 결과로 연결되는가?

## 📋 Step 2: 3년 전략적 목표 수립

### 2.1 연도별 목표 설정

**연도별 목표 수립 과정:**
1. **현재 상황 분석**: 프로젝트 현재 상태 파악
2. **시장 분석**: 시장 상황 및 경쟁 환경 분석
3. **기술 트렌드**: 향후 3년간 기술 변화 예측
4. **단계별 목표**: 연도별 달성 목표 설정

**연도별 목표 템플릿:**
```markdown
### [연도]년: [주요 테마] ([상태]) [아이콘]
**목표**: [연도별 핵심 목표]
- **Q1**: [1분기 목표] [상태 아이콘]
- **Q2**: [2분기 목표] [상태 아이콘]
- **Q3**: [3분기 목표] [상태 아이콘]
- **Q4**: [4분기 목표] [상태 아이콘]
```

**상태 아이콘 가이드:**
- ✅ 완료
- 🔄 진행 중
- 📋 계획 중

### 2.2 목표 간 연결성 확인
**연결성 체크리스트:**
- [ ] 각 연도 목표가 비전 달성에 기여하는가?
- [ ] 연도별 목표가 논리적으로 연결되는가?
- [ ] 선행 목표가 후행 목표의 기반이 되는가?
- [ ] 전체적으로 일관된 방향성을 가지는가?

## 📋 Step 3: 핵심 가치 제안 정의

### 3.1 사용자 가치 정의
```
❓ 질문: "사용자가 이 프로젝트를 통해 얻을 수 있는 핵심 가치는?"
```

**사용자 가치 템플릿:**
```markdown
### 사용자 가치
- **[가치 유형 1]**: [구체적 가치 설명]
- **[가치 유형 2]**: [구체적 가치 설명]
- **[가치 유형 3]**: [구체적 가치 설명]
```

**예시:**

```markdown
- **협업**: 실시간 팀 협업 및 피드백
```

## 📋 Step 4: 기술 전략 수립

### 4.1 핵심 기술 스택 정의

**기술 스택 선정 기준:**
- **확장성**: 향후 3년간 확장 가능한 기술
- **안정성**: 검증된 기술 스택 사용
- **생산성**: 개발 생산성을 높이는 기술
- **인재 확보**: 개발자 확보가 용이한 기술

**기술 스택 템플릿:**
```markdown
### 핵심 기술 스택
- **Frontend**: [기술 스택]
- **Backend**: [기술 스택]
- **Database**: [기술 스택]
- **Infrastructure**: [기술 스택]
- **AI/ML**: [기술 스택] (해당 시)
```

### 4.2 아키텍처 원칙 정의

**아키텍처 원칙 템플릿:**
```markdown
### 아키텍처 원칙

- **[원칙 2]**: [설명]

- **[원칙 4]**: [설명]
```

### 8.1 승인 대상자
