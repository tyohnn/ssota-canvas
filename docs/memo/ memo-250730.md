2. 캔버스 모드 비즈니스 로직 정리

- 캔버스 모드에서는 explorer가 데이터, 템플릿 인스턴스, 체크리스트 페이지가 가능. DB에 타입을 정의하고 이는 폴더로 구분. IA 템플릿 클래스는 IA 폴더가 생김.
- 유저가 직접 페이지를 생성할 수 있음 -> 페이지의 종류를 선택할 수 있음 (테이블, 마크다운, 다이어그램, 템플릿 클래스, 체크리스트) 템플릿 클래스, 체크리스트 등은 다이나믹하게 렌더링
- 폴더로 구분할 수 있음 -> 폴더 노드 / 폴더는 1차원 구조
- 테이블, 마크다운, 다이어그럄 모두 DB 상으로는 노드임.
- 노드 정의 노드는 프레이머처럼 다른 캔버스가 열림. 정의할 수 있는 편집기 느낌.
- 기본 노드 우클릭해서 컴포넌트화 하기로 넘어가면, 노드 정의 노드로 넘어감.

1. 유저가 캔버스에 들어온다. 아무것도 없다.
2. 페이지 추가하기 버튼을 클릭하면, 마크다운, 다이어그램, 테이블 중 하나를 선택할 수 있다. (워크플로우는 없다는 가정. 템플릿 결과물, 데이터, 체크리스트는 선택 못함)
3. 다이어그램 선택 -> 바로 리액트 플로우 패널이 열리면서, 에디터 패널 열림. 제목, 설명 등 기본 데이터 채우기
4. 블럭 추가하기 -> 기본노드와 컴포넌트화한 노드 (워크플로우에서는 노드 정의 노드와 같음), 다른 페이지들 선택 가능 (프레이머 insert처럼 explorer 형태가 나을수도)
5. 기본 노드 클릭 -> 에디터 패널 열리고, 다이어그램에 추가됨. 기본 값 채우기, 디자인 설정, 추가 메타데이터 추가 가능. Page라는 이름, 속성 url, 색상 등 설정
6. 페이지1 우클릭 -> 컴포넌트화하기 -> 컴포넌트 에디터 열림. 현상태로 저장
7. 블럭 추가 버튼 -> 컴포넌트화한 page 노드가 있음. 이거를 클릭하면, 캔버스에 추가되면서 에디터 패널 열림. 컴포넌트 메타데이터 채우기.
8. 엣지 연결 -> 노드1에서 노드2로 연결 -> 엣지 에디터 나옴 -> 메타데이터 채우기
9. 페이지 추가하기 / 마크다운, 테이블도 해보아야 함.
10. 에이전트에게 나 이러이러한 서비스 만들건데, IA 구성해줘.

캔버스 모드 에이전트가 가진 툴

1. 노드 추가하기 -> 인풋: 자연어, 아웃풋: 사이퍼 문법 -> add_node: 여기 안에 변환기 있음
2. 엣지 연결하기-> 인풋: 자연어, 아웃풋: 사이퍼 문법 -> add_edge: 여기 안에 변환기 있음
3. 노드 검색하기 -> 인풋: 쿼리, 아웃풋: 특정 업무를 수행하기 위해 특정 데이터를 직접 찾는다. -> search_block: 쿼리로 제목, 메타데이터에 들어간 노드를 찾는다. 검색은 메타데이터로 한다.
4. 관계 검색하기 -> 인풋: 쿼리, 아웃풋: 특정 업무를 수행하기 위해 특정 관계를 직접 찾는다.
5. 마크다운 수정하기 (마크다운 페이지에서)
6. 칼럼 추가하기 (테이블 페이지에서)
7. 로우 추가하기 (테이블 페이지에서)
8. 칼럼 수정하기, 로우 수정하기
9. 노드 컴포넌트 검색
10. 웹검색
