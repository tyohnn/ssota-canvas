# SSOTA v0.5 Landing Page Plan (Canvas-based Research Agent)

## 목표

* “AI 리서치 툴을 이미 써본” 야망 있는 유저가 **0.1초에**
  **(1) SSOTA가 무엇인지** + **(2) 왜 필요한지(whole picture/format limit)**를 이해하고
* 데모 섹션에서 즉시 체험 → 가입/대기 리스트/설치 등 전환.

## 타겟

* Ambitious, hard thinker/hard worker
* 구조화/시스템을 좋아하지만 **노트/챗/리포트 포맷의 한계**를 느끼는 사람
* 직군: 컨설턴트/투자/전략/PM/사업가/리서처 등 범용

## 핵심 메시지

* **Notes, chat, reports가 사고를 “정의”한다 → 전체 그림이 깨진다**
* SSOTA는 **one canvas**에서 **AI agent + templates**로
  리서치를 **구조화하고 다음 단계(Plan/Decision/Next big thing)**로 밀어준다.

# S2. Demo (Interactive Tabs)

### 목적

“말”이 아니라 “체감”.
특히: **one canvas + agent + templates + next step**를 보여줌.

### 구성

탭 4개 + 각 탭마다 미리 준비된 React Flow 캔버스(프리셋)

* Tab 1: **Summarize**
* Tab 2: **Structure**
* Tab 3: **Organize**
* Tab 4: **Deliverables**

각 탭 공통 UI

* 좌: Canvas (프리셋 보드)
* 우: Agent panel (액션 버튼 + 간단 결과 프리뷰)

#### Tab 1 — Summarize

* Input: YouTube URL 카드(또는 PDF 카드)
* Action: Summarize
* Output: Key points 카드(짧은 리스트) + (가능하면) timestamps/sections

#### Tab 2 — Structure

* Input: 여러 소스가 놓인 상태
* Action: Choose template → Apply
* Output: 캔버스에 섹션 프레임(Outline)이 생기고, 소스/요약이 섹션으로 배치됨

#### Tab 3 — Organize

* Toggle: Canvas ↔ Table ↔ Kanban ↔ Timeline
* Output: “같은 보드, 다른 뷰”를 보여줌(데이터 일관성 강조)

#### Tab 4 — Deliverables

* Action: Generate plan (or decision options)
* Output: 우측에 Plan 프리뷰(짧은 포맷) + “Copy / Export” CTA(초기엔 Copy만)

### 데모 섹션 타이틀/한줄

* Title: **Try SSOTA in 30 seconds.**
* One-liner: **Drop a YouTube link. Watch it become a plan.**

# S3. Features / Differentiators (Bento Grid)

### 목적

데모로 납득한 뒤 “왜 SSOTA여야 하는지”를 한 줄씩 못 박기.

### 레이아웃

Bento grid 2x3
각 카드: Title 1줄 + Text 1~2줄 + micro animation(svg clip)

### 카드 카피 (최종 반영)

#### Card 1 — Beyond chat (휘발성/저장)

**Title:** Chat disappears. Boards stay.
**Text:** Keep research on a canvas you can revisit and extend.

#### Card 2 — Agent (보드에서 같이 일함)

**Title:** The agent works on your board.
**Text:** It reads the whole canvas and helps you keep building forward.

#### Card 3 — Format 탈출 (사용자 요청 반영)

**Title:** Stop thinking in chat boxes.
**Text:** Notes, chat, and reports limit how you think. SSOTA is a canvas for big-picture thinking.

#### Card 4 — Multi-format inputs

**Title:** Bring real sources.
**Text:** Links, YouTube, PDFs, and audio—SSOTA turns them into usable building blocks.

#### Card 5 — Multi views (Organize)

**Title:** One board, many views.
**Text:** Canvas, table, kanban, timeline—switch views without rewriting.

#### Card 6 — Next step outputs

**Title:** From research to a plan.
**Text:** Turn the board into next-step work: plan, decision, direction.
