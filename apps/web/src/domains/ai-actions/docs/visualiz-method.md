Below is a **big menu of 2D-canvas templates/layouts** you can use to “study” YouTube lectures/podcasts (not just summarize). I’m mixing:

* **Miro template families** (Mind maps, Concept maps, Flowcharts, Affinity diagrams, Fishbone, 5 Whys, Timelines, etc.) ([미로][1])
* **Research/insight synthesis boards** (very relevant to “collect → connect → structure → insight”) ([미로][2])
* **Learning/visible-thinking routines + classic note-taking** (good for deeper understanding) ([Project Zero][3])
* **Education “graphic organizers”** (tons of reusable layouts) ([Book Creator app][4])

---

## 1) Timeline-first (when the content is “a story / lecture flow / step-by-step”)

1. **Chapter Timeline** — timestamps → “what changed at this point?” (great for podcasts) ([미로][5])
2. **Milestone Timeline** — “key turning points + why they matter” ([미로][6])
3. **Before → After Timeline** — “beliefs/assumptions before vs after section N”
4. **Problem → Attempts → Breakthrough** timeline (great for technical talks)
5. **Claim Evolution Timeline** — how the speaker’s thesis gets refined
6. **Example Timeline** — each example placed on the timeline, linked to the concept it illustrates
7. **Quote Timeline** — anchor “high-signal quotes” to exact timestamps
8. **Confusion Timeline** — mark “unclear parts” (questions) at timestamps for rewatch
9. **Action Timeline** — “do this now / later” tasks aligned to sections
10. **“Two-layer” Timeline** — top lane: chapters; bottom lane: your insights/questions

---

## 2) Network maps (when the goal is “connect ideas & build structure”)

11. **Mind Map** — central topic → branches → sub-branches (fast capture) ([미로][1])
12. **Concept Map** — nodes + labeled relations (“causes,” “is part of,” “leads to”) ([미로][7])
13. **Term/Definition Graph** — glossary nodes linked to where used
14. **Framework Map** — “components of a model” + how they interact
15. **Cause → Effect Network** — multiple causes feeding outcomes (not linear)
16. **Analogy Map** — “speaker’s metaphor → what it maps to”
17. **Evidence Graph** — Claim nodes linked to Evidence nodes, Counterclaim nodes
18. **“FAQ Graph”** — question nodes connected to answer nodes and examples
19. **“Bridge Map”** — old belief → new belief → bridge (what changed your mind)
20. **Multi-video Topic Map** — multiple videos connected into one topic lattice (great for your “collect & connect” workflow)

---

## 3) Process & decision templates (when the content is “how-to / operational”)

21. **Flowchart** — steps + decision diamonds (classic) ([미로][8])
22. **If–Then Decision Tree** — branching consequences (great for strategies) ([미로][9])
23. **Yes/No Flowchart** — minimal decision tree ([미로][10])
24. **Cross-functional Flowchart (Swimlanes)** — “who does what” across roles ([미로][11])
25. **Checklist Canvas** — steps + acceptance criteria + common failure modes
26. **Playbook Board** — “situation → recommended action → pitfalls → example”
27. **Operating Procedure Map** — SOP blocks + “why this step exists”
28. **Troubleshooting Tree** — symptom → diagnosis → fix (great for tech content)

---

## 4) Synthesis boards (when you want “insights,” not “notes”)

29. **Affinity Diagram (Clustering)** — dump nuggets → cluster → name themes ([미로][12])
30. **Insight Synthesis Board** — themes → insights → implications → actions ([미로][2])
31. **“Observation → Insight → Recommendation” ladder**
32. **Signal vs Noise Board** — keep only repeatable/generalizable concepts
33. **Pattern Library** — “pattern name → when it appears → examples → anti-pattern”
34. **Contradictions Board** — where ideas clash; resolve by adding conditions (“works when…”)
35. **Principles Board** — extract “rules” + boundary conditions + exceptions
36. **Mental Models Gallery** — each model gets a card: definition, mechanism, example, warning
37. **“Compression Layers” Board** (Progressive Summarization) — raw notes → highlights → distilled takeaways ([Forte Labs][13])

---

## 5) Root-cause / systems-thinking (when content explains “why things happen”)

38. **5 Whys** — one problem → 5 layers of “why” ([미로][14])
39. **Fishbone (Ishikawa)** — categorize causes (People/Process/Tools/Env…) ([미로][15])
40. **Causal Chain Map** — “A leads to B leads to C” with evidence links
41. **Feedback Loop Sketch** — reinforcing vs balancing loops (systems view)
42. **“Leverage Points” Board** — where small changes produce big effects
43. **Constraint Map** — bottlenecks + downstream symptoms

---

## 6) Compare / evaluate (when content is “choices, trade-offs, debates”)

44. **2x2 Prioritization Matrix** — impact vs effort, etc. ([미로][16])
45. **Decision Matrix** — options scored by criteria ([미로][17])
46. **Pros/Cons + Conditions** — “pro if…, con if…” (prevents shallow lists)
47. **Compare–Contrast Grid** — rows=features, cols=options
48. **Venn Diagram** — overlaps (useful for competing theories)
49. **Debate Map** — thesis vs antithesis → synthesis
50. **Assumption Map** — assumptions → risks → tests

---

## 7) “Thinking routines” as templates (amazing for lecture → deep learning)

These are basically **ready-made prompts + canvas regions**:

51. **See–Think–Wonder** — observe → interpret → questions ([Project Zero][18])
52. **Claim–Support–Question** — claim → evidence → open questions ([Project Zero][19])
53. **Connect–Extend–Challenge** — connect to prior knowledge → extend → challenge/uncertainty ([Project Zero][20])
54. **Circle of Viewpoints** — multiple perspectives (great for podcasts with opinions) ([Project Zero][21])
55. **3-2-1 Bridge** — 3 thoughts / 2 questions / 1 metaphor → revisit after learning ([Project Zero][21])
56. **Generate–Sort–Connect–Elaborate** — literally a “knowledge graph builder” routine ([Project Zero][21])

---

## 8) Classic study note layouts (works well as “panels” on a canvas)

57. **Cornell Notes** — cues/questions | notes | summary ([요크 대학교 주제 가이드][22])
58. **Outline Notes** — hierarchical bullets + section headers
59. **Charting Method** — columns by theme (concepts/examples/definitions)
60. **Q/A Notes** — left=questions, right=answers + evidence
61. **Feynman Sheet** — explain simply → find gaps → refine
62. **One-page “Cheat Sheet”** — constraints: 1 screen / 1 page only
63. **Sketchnotes / Visual Note-taking** — icons + containers + arrows (very canvas-native) ([Indiana Libraries Guides][23])

---

## 9) Education “graphic organizers” you can steal endlessly

64. **KWL Chart** — Know / Want to know / Learned ([Google Drive][24])
65. **Frayer Model** — definition / characteristics / examples / non-examples ([balancedtech.org][25])
66. **Sequence Chain** — steps in order ([balancedtech.org][25])
67. **Cause–Effect Organizer** — structured causal reasoning ([balancedtech.org][25])
68. **Vocabulary Map** — term → definition → context → example
69. **Main Idea / Supporting Details Map**
70. **Problem–Solution Organizer**
71. **“Big Ideas” Organizer** — 3–5 big ideas, each with 2–3 proofs/examples
    (There are **100+** variations you can adapt. ([Book Creator app][4]))

---

## 10) “Multi-video synthesis” templates (your “collect → connect → insight” goal)

72. **Hub-and-Spoke Board** — central “Topic Hub” + spokes for each video, all linking into shared concepts
73. **Map of Content (MOC) Board** — an index map: topics → subtopics → canonical notes (great for long-term knowledge building) ([cogneon.github.io][26])
74. **Concept Library + Evidence Library** — separate spaces: “concept cards” and “evidence/quotes cards,” linked
75. **Contradiction Resolver Board** — group conflicting claims from multiple videos, then add conditions to reconcile
76. **“Insight Garden”** — clusters of evergreen insights that evolve over time (versioned)

---

# How this translates into “Smart Summary” for your YouTube block

If you want **one universal, production-friendly default**, I’d pick a **3-panel canvas**:

1. **Timeline (chapters + key moments)**
2. **Concept Graph (10–30 nodes max, labeled edges)**
3. **Synthesis Zone (Themes → Insights → Actions + Open Questions)**

This combo matches how Miro-style templates are typically used (timeline/process + mapping + synthesis). ([미로][5])

If you tell me your *target output size* (e.g., “one screen only” vs “dense board”), I can propose **a minimal set of 5 template presets** (and what nodes/edges you’d want in Canvasdown for each preset).
